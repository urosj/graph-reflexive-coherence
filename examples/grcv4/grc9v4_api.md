# Public GRC9V4 API

The maintained [progressive native guide](../grc9v4/README.md) starts with one
positive step, then covers all ten candidate/realization contracts, histories,
seed and spark diagnostics, basin observations, mechanical expansion, profile
and branch migration, reset/rebase, checkpoint replay, failures and numerical
policies. Its runnable lessons and retained results use the public API.

All ten families now have bounded native execution; the earlier four-family
restriction in this guide is historical. Arbitrary inputs still require native
admission. Completed sparks, hierarchy and general autonomous topology selection
are not implied by mechanical expansion or basin diagnostics.

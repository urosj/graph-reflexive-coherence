# B2-GR Hypotheses And Claim Boundaries

These are constructibility hypotheses over unchanged `GRC9V3`. They are not
predictions that a positive witness must exist.

## Hypothesis A - Branch-Relative Slow Retention

At least one preregistered runtime-reached preparation may leave a persistent
state difference that is distinguishable from relocation within the same
fixed-configuration formed-state manifold and occupies an isolated temporal
slow cluster.

Support requires:

```text
unchanged_runtime = true
preparation_provenance = native_spontaneous | runtime_realized_from_upstream_preparation
accepted_B1_branch_ancestry = true
fixed_topology_event_free_primary_lane = true
forming_intervention_exhausted = true
driver_does_not_directly_author_carrier = true
native_carrier_formation_attributed = true
carrier_lineage_id = frozen
branch_relation_class = same_branch_transverse_retention_candidate
same_configuration_branch_relocation_rejected = true
isolated_slow_cluster = true
temporal_operator_domain = admitted_complete_step_causal_state
carrier_projection_of_slow_cluster = established
primary_metric_and_projector_predeclared = true
conditioning_and_uncertainty_gates = passed
nonzero_admissibility_margin = true
multi_horizon_persistence = passed
maximum_rung = GRR3_or_stronger
```

Finite-window persistence, tangent displacement, synthetic-only preparation,
eventful history, zero-margin threshold contact, parameter-continuation alignment
alone, or reduced frozen-`W` sensitivity cannot support A. History-induced
branch relocation remains an alternative outcome rather than disappearing as a
generic failure.

## Hypothesis B - Carrier-Conditioned Later Probe

At least one Hypothesis A carrier may change the incremental response to a
later matched native probe, rather than merely changing the no-probe baseline.

Support requires:

```text
hypothesis_A_row = supported
same_carrier_lineage_as_hypothesis_A = true
carrier_by_probe_2x2_contrast = passed
carrier_class = C_sector | W_sector | joint_C_W_sector | i2_enumerated_existing_sector_id
noncarrier_match_provenance = naturally_matched_pair | runtime_constructed_matched_pair
full_noncarrier_causal_state_matching = passed
carrier_separation_margin = positive
zero_probe_control = passed
probe_reads_carrier_before_rewrite = true
native_probe_lane = full_step_or_immediate_stage
mediation_path_attributed = true
probe_amplitude_rule = passed
maximum_rung = GRR4_or_stronger
```

A probe main effect, baseline transport difference, synthetic counterfactual
match, analytical probe, or reduced frozen-`W` response cannot support B.
The GRR4 zero-probe control is not the stronger core Read-Back passive-null
condition.

## Hypothesis C - Controlled Retention/Mediation Candidate

At least one Hypothesis B row may survive write attribution, persistence,
reset, swap, bypass, replay, witness-validity, and active-null controls under
the frozen scope. Robustness characterization is reported separately and need
not be broad for a valid deterministic constructibility witness.

Support requires:

```text
hypothesis_B_row = supported
single_carrier_lineage_for_write_GRR3_GRR4_and_controls = true
write_attribution = passed
persistence = passed
mediation = passed
reset_control = passed
swap_control = passed
control_applicability_matrix = satisfied
required_bypass_control = passed_or_not_applicable_by_frozen_rule
all_required_replays = passed
all_active_nulls = failed_closed
witness_validity = passed
required_control_not_identifiable = false
maximum_rung = GRR5
```

`GRR5` supports only a bounded retained-geometry or joint-retention candidate.
It does not establish core Read-Back, write-back, or a closed loop.

## Hypothesis D - Claim-Clean Route Decision

B2-GR can classify the unchanged-runtime constructibility result without
turning bounded search failure into impossibility or automatically selecting a
runtime extension.

Hypothesis D passes only if:

```text
source_and_artifact_identity = complete
row_local_provenance = complete
failed_searches = retained
rivals_and_uncertainty = retained
native_reduced_synthetic_lanes = separated
bounded_negative_unresolved_and_nonidentifiable = separated
witness_validity_and_robustness = separated
global_max_GRR_equals_max_row_local_GRR = true
GRR_and_B2_closeout_ladders = separated
extension_selection_requires_target_and_missing_role = true
unsafe_claims = false
```

Hypotheses A-C may fail while D passes. If D fails, no positive A-C row may be
consumed downstream regardless of its local margin.

## Blocked Relabels

```text
same-configuration branch relocation -> branch-relative retained carrier
parameter-continuation tangent -> same-configuration branch relocation
finite-horizon persistence -> isolated slow mode
baseline transport difference -> read effect
frozen-W sensitivity -> native mediation
synthetic-valid preparation -> runtime-reached formation
directly authored carrier -> native carrier write
cross-lineage rung composition -> cumulative GRR5
eventful persistence -> fixed-topology retention
zero-margin threshold contact -> clean constructibility witness
synthetic matched pair -> native mediation
probe-induced carrier rewrite -> read of pre-existing carrier
stage-skipping bypass -> native causal control
non-identifiable control -> failed mechanism
cross-branch non-generalization -> invalid witness
GRR5 -> core Read-Back
failed bounded search -> impossibility
missing role -> extension necessity
retention -> memory, learning, identity, or agency
```

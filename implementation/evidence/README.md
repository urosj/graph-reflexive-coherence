# Implementation evidence

This directory holds retained measurement and acceptance artifacts linked from
implementation plans and closeouts. Evidence is grouped by subject:

- [GRCV4 performance](grcv4-performance/README.md): grid benchmarks, exact
  numerical-work counts, strict public-result comparisons, and source hashes.
- [Causal pathway binding](causal-pathway-binding-iterations/README.md):
  iteration and audit evidence for the causal pathway binding work.

The documents that interpret a change remain with its implementation record;
raw measurements and their paired comparisons remain here.

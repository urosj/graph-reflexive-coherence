The public GRC9V4 interface now exposes `basin_attributes` and the derived partial

## Implementation and use

[`grc_9_v4_basin.py`](../../../src/pygrc/models/grc_9_v4_basin.py) captures one
fresh read per role. Current, geometry, rows and classification consume that
capture. CI binds the complete selected joint point and certificate, not just J;
PC reads the role's committed carrier. Both roles are reconstructed before the
existing sole publication point. No diagnostic enters authoritative C/W/Z or a
second mutable owner. Observation witnesses retain exact finite `float.hex()`
operands, including signed zero, plus state/context/model/evaluator bindings.

Membership follows every represented nonzero current through SCCs to terminal
components. No threshold or strongest-edge shortcut is introduced. Regions
cover only assigned nodes; SCCs and node records cover the entire graph.
The seed predicate uses exact rational squares of represented binary64 operands.
Typed IDs, component/node/member ordering and derived collections are checked,
including after a record is rehashed.

For a new model, explicitly replace the configuration specialization:

```python
from dataclasses import replace
from pygrc.models import GRC9V4

successor = replace(config, specialization=config.specialization.with_basin_policy())
model = GRC9V4(successor)
observation = model.compute_observables()["basin_attributes"]
assignments = model.state.lifecycle.basin_identity
```

For an existing enabled v1 model, use
`model.migrate_basin_policy("enable-basin")`. This journals the explicit model
identity change, preserves generic profile/state/context and re-admits both
histories. Old v1 configurations and checkpoints are never silently upgraded.
An event request must bind the actual v2 scientific state and target specialization.

`model.snapshot(replay_mode="exact_observation")` retains and checks both exact
observations. `replay_mode="state_only"` explicitly stores null observation slots
and reconstructs fresh observations on restore. There is no fallback between the
modes. Disabled delegation omits basin diagnostics and returns the legacy result.

## Focused execution and pressure

Four small native fixtures reuse the retained P9-9.1b input declarations. They
have distinct current/reset authority. Each family checks:

- Fresh native capture and public/wire correspondence; one read per observation.
- Explicit policy migration, mechanical expansion and positive target evolution,
  reset/rebase, assignment, save/load and both replay modes.
- Rehashed role/root/row/order corruption, stale native reads, reset-only failure
  in step/reset/rebase/profile migration/expansion, and late publication failure.
  The complete publication pointer, including histories and receipts, survives.
- Same-profile migration, exact disabled observables, replay and enabled return.

Four additional tests compare all 64 three-node directed supports against an
independent transitive-closure oracle, and pressure cycles, loops, isolates,
competing routes, opposite parallel subnormal currents, signed zero, typed empty
string/int/string IDs, partial region coverage, exact seed boundaries and numeric
underflow/overflow. Ten v2 public declarations round-trip; six unselected native
families still reject before execution.

The retained `P9-10.1a-Native-{family}.json` records contain source/input identities,
test roster, interpreter/backend versions, current/reset lossless observations and
final observation bundles. They do not retain redundant checkpoint journals.
The scientific model, step size and admission tolerances are unchanged. This is
bounded native conformance with FLINT and `legacy_exact_v1`, not a uniform
all-graph numerical theorem or a cross-platform bitwise guarantee.

During fixture integration, old event requests correctly rejected both the new
specialization identity and the new model-bound source digest. The tests now name
the actual v2 source/target identities; allocation/history policies and numerical
criteria are unchanged. Routine failed development outputs are not retained.

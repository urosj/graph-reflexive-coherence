## Independent comparisons

The [oracle](../verification/p9101a_basin_oracle.py) computes Boolean transitive
closure, derives mutual-reachability classes, and compares every SCC, terminal,
reachable-terminal set, node status, sink, basin ID, seed, region member and
partial public assignment. The producer uses Kosaraju. Exact rational seed
arithmetic consumes represented operands; it does not threshold small currents.
All 64 three-node directed supports and named edge cases exercise the production
classifier, including reconvergence, competing terminal kinds, upstream cyclic
components, loops, opposing parallel subnormals, signed zeros, mixed typed IDs,
empty graphs and strict seed equalities. These are **synthetic classifier cases**.

The [native tests](../verification/test_p9101a_basin_pressure.py) detach complete
state by serialization/reconstruction **before** giving the producer access.
A read-only spy captures the real native selected read. Every edge hex value,
endpoint, row, role, context, profile, evaluator and complete root binding is
checked against that saved state and capture. Fraction row sums independently
use committed A history or the complete C stable-edge reference map. Unequal
neighbors and nonuniform weights make the row checks discriminate substitutions.
C reference Hodge and W_C_tr are changed together as their accepted declaration
requires; this is not independent Hodge-to-mobility authority.

The independent interval equations are reused from the reviewed small fixed-row
research evaluator. Their assumptions are checked: zero structural base,
fixed parameters, diagonal reference geometry, connected graph and a certified
constant-only C selector gap. The C weighted companion retains explicit stable
edge mobility; it does not infer it from generated geometry. Current error is
enclosed at the **captured represented geometry**. CI's joint geometry equation
is checked separately. A fixed-geometry error bound is not labeled a full CI
fixed-point error certificate or an exact-root sign proof. The classification
oracle always uses the represented currents, including unresolved near-zero
ones.

## Category and lifecycle scope

Each family supplies admitted examples with a unique sink region, branching
ambiguity, and quiescence. Supplied-state examples and post-operation observations
are labeled separately. Positive ordinary evolution, assignment, reset, rebase,
same-profile migration, both load modes, and a supported mechanical expansion
are checked against actual resulting states and graphs. Expansion's 17-node
target is independently evaluated; source labels are not reused. The earlier
native suite retains the broader reset-only failure/replay matrix.

The retained case labels identify the deterministic sequences in the bound test:
`initial → after_positive_step`; a separate observer/control pair runs a positive
step, reset, rebase, assignment of the control state, same-profile migration,
then one load in each mode. `after_supported_expansion` starts a separate original
fixture, executes its zero-duration prefix and the retained P9-9.1b expansion
request with the actual v2 source/target identities. Supplied, weighted and matched
W/Z cases begin from explicit configuration changes, not claimed trajectories.

All four selected declarations have epsilon_gradient = epsilon_Hessian = 1/2.
A seed requires epsilon_gradient² > 3 epsilon_Hessian² because every signed
diagonal must exceed epsilon_Hessian. Thus **positive seeds are impossible for
these exact declarations**, including at partially occupied nodes. Thresholds
are not changed to fabricate a native positive seed; positive seeds and strict
boundaries remain classifier-level tests.

Native recirculation is not claimed. A's exact fixed-geometry positive-denominator
potential law excludes directed cycles where its signs hold; the independently
checked denominator and represented-sign margins are retained. This does not
promote unresolved near-zero represented signs to exact-law facts. C cycle
non-observation is not an impossibility theorem. General attractors, physical
basin identity transport and six additional native families remain outside scope.

One observer/non-observer pair receives identical requests and must produce
identical authoritative state and receipt history. Read, classifier, serialization,
and reset-only preparation failures preserve the complete publication. Coherent
forgeries alter the last edge or node and recompute hashes and classification;
they pass internal graph consistency but fail saved-state provenance. Swapped
role captures and producer input mutation are also rejected. A standalone
serialized graph validator does not authenticate native origin: the capture-bound
validator and replay checks supply that boundary.

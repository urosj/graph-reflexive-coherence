## Focused execution

[Four test methods](../verification/test_p974_target_reference.py) cover:

1. Forty declaration rejections: missing, extra, same-size foreign-key,
   duplicate, zero, negative, NaN and infinity maps across five C profiles.
   Finite extra/foreign maps have recomputed identities and must fail exact
   live-edge coverage. Duplicate keys are tested as raw JSON, before a mapping
   could silently collapse them. These are construction/wire rejections, not
   forty executed lifecycle events.
2. Native event admission for C_OS, C_CI, C_RG2b, C_PC and C_CI+PC. Observe
   actual successful numerical evaluations for distinct current/reset resources
   before the publication validator; assert the old publication remains live.
   Verify absent W_A/initializer pairs and exact snapshot restoration.
3. A two-vertex source to three-vertex, three-edge C_OS target, including parallel
   edges, nonuniform target weights and a map whose insertion order differs
   from edge order. Independent dense equations check selector, sector, retained
   Hodge, potential, baseline, total current and active Read-Back for both roles.
   Literal diagonal Hodge/mobility checks distinguish their authorities.
   Restore and reset use the new target, not source-derived arrays.
4. A real reset-only C_PC resource-chart rejection for event and migration,
   each with a passing current-as-reset control. Neither rejection reaches
   publication; state, reference, receipts, commits and transition archive stay
   under the original whole-publication pointer. An injected unexpected late
   publication error also propagates without replacing that pointer.

The record retains inputs, target references, requests, numerical-role outputs,

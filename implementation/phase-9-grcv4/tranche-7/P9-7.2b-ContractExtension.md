## Bounded decision

Use the graph-generic fallback already permitted by proposal/paper §12.7:
map both resource states, use the accepted target-only reference-pass producer
for A targets, and explicitly drop/reset source history where this selected
policy does not transport it. Preserve the two independent history channels.
C→A has no candidate loss; NP→P has no carrier loss. A→A fallback discards W;
P→P fallback discards Z even for the same candidate. Resource-map injectivity
is a separate question, not certified by those labels.

The [new V4 supplement](../../../specs/grc-v4-topology-event-spec.md) owns the
exact policy matrix, event receipt v2, snapshot layout, current/reset producer
binding, charge/admission/rollback rules and release boundary. The
[schema](../../../specs/grc-v4-topology-event-schema.json) and
[synthetic vectors](../../../specs/grc-v4-topology-event-vectors.json) are
additive. No accepted paper/proposal text or older schema is edited: the
mathematical route is already present. This is an implementation-contract
specialization of that route, not a new scientific claim or a claim that D10
already supplied the new wire version.

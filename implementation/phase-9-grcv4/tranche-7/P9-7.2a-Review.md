module only constructs/checks deterministic history policies and maps C/W/Z;
existing numerical owners perform source and target state readmission, including
both current and reset. No ordinary writer, continuity update or clock advance
is performed by a migration. RG2b readmission uses its state chart, not the next
beat's smaller entry chart. Generic topology events remain P9-7.2b.

History digests use the frozen `history_content_identity_payload`: current
then reset in graph edge/tensor order, two equal-sized halves bound by the
receipt's graph/profile and full source/target authority identities. Candidate
and carrier channels remain distinct. Source arrays are retained in immutable
crossing preimages when dropped; they are not restored as active target history.
PC/CI+PC preservation requires exact carrier/base/geometry/writer/tau/norm/domain
identity, while only the immediate CI path is added/removed.

A separate closed `pygrc-generic-migration-snapshot-v1` envelope retains the
reference and A differential-recipe registries needed to replay/readmit every
archived endpoint, including after A→C. The active backend is selected from
the same immutable reference publication, not a separately mutated pointer.
Existing single-profile generic and C_OS layouts remain unchanged.

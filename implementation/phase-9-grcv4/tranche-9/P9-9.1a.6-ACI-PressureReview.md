## Scope and limits

The native witness uses fixed duration 32, tau_A=32, C in [0,4], W strictly
between 0.99 and 1.01, and the certified inactive-floor chart. Arbitrary small
durations, active-floor evolution and generalized writer semigroup behavior
are not implemented by this profile. The held-target logarithmic-writer control
is a primitive check, not a semigroup claim for the coupled step.

The native ordinary-step API requires positive duration 32. Zero-duration
requests reject without state, writer or observation-window progress; read-only
inspection preserves identity. No arbitrary-duration support was added to satisfy
a broader suggested test.

Different starting guesses are tested by the independent mathematical checker.
Production remains the declared zero-start, fixed-Arb256 policy; no warm-start
cache or branch selector was added. Root uniqueness is only in the declared ball.

The geometry effect is small but measurable: see the exact lower bounds in
measurements.resolved_geometry. The current effect is at least 1.22e-18, compared with the 1.59e-58 midpoint
budget. The comparison uses rigorous bounds, not
rounded display values or the mere fact that geometry code executed.

Fifteen combined preflight/pressure publication checks pass. API, browser and
notebook expose the pressure result alongside the original
preflight and reject stale or forged evidence. Reprofile the complete campaign
checker before .5; the original **16.2/30.5-minute** estimate describes the
preflight checking path, not this stronger audit. No long campaign was run.

updates for each role. These predictions test finite/nonnegative resources;
they do not prove native continuation or an accumulated error bound.

Each role then receives a read-only native `CandidateCIRoot` proposal. Its full
selected joint point retains J and H, generated H, baseline, lowered read,
Read-Back and structural source. Checks bind the full selected J/H input,
root/point identities, same-root source/geometry, domain ID, residual and
whole-ball certificate; independent numerical bounds cover geometry, current,
baseline and structural source. The native Frobenius radius is `2^-18`;
the separate independent infinity-norm geometry ball has radius `2^-20`.
The two domains are not identified merely because they admit the same point.
Independent 60-digit interval equations bound root, current and source errors
at each actual saved entry. Ceilings remain `2^-48`, `2^-40` and `2^-64`
respectively; the declared joint residual tolerance remains `2^-44`.

Native event owners, expansion allocation and ordinary native steps are
disabled in this preparation command. Read-only native root proposals are

No receipts, committed events, native target steps or runtime-cell acceptance
are produced here. The independent ten-step predictions do not establish
the native joint-root/domain contracts at the later trajectory entries.

## Retention and reproduction

Source inputs are retained once, with exact D45 preparation references.
New rows retain only the selected target joint roots/certificates and independent
nominal C/J predictions consumed by the checker. Full target references are
deterministically reconstructed from the frozen cases. The preparation budget
is below 10 MB, with no interrupted dumps or external paths.

From repository root:

```bash
python scripts/evidence_storage.py restore
PYTHONPATH=src .venv/bin/python implementation/phase-9-grcv4/verification/p984c_cci_preparation.py --prepare
PYTHONPATH=src .venv/bin/python implementation/phase-9-grcv4/verification/p984c_cci_preparation.py --run-prerequisites
PYTHONPATH=src .venv/bin/python implementation/phase-9-grcv4/verification/p984c_cci_preparation.py --check-retained
PYTHONPATH=src .venv/bin/python implementation/phase-9-grcv4/verification/p984c_cci_preparation.py --check-retained --recheck-numerics
PYTHONPATH=src .venv/bin/python -m unittest discover -s implementation/phase-9-grcv4/verification -p test_p984c_cci_preparation.py -v
```

Existing evidence is never overwritten; a fresh prerequisite run may use a
repository-relative `--output`. Plain retained checking reconstructs target
references, validates joint-root identities/bounds and checks prediction
continuity without solving new native roots. `--recheck-numerics` additionally
recomputes independent interval equations and nominal predictions, still without
native roots, steps or events. Neither mode confers runtime acceptance.

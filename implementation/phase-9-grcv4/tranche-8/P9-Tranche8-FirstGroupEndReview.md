# Final Tranche 8 reviews — bounded first group

Scope: C_OS, C_CI, A_CI and A_PC. P9-8.6 is accepted on 2026-10-27 in the
[separate acceptance record](./P9-8.6-FirstGroupAcceptance.json). These reviews
do not reopen it, grant public support or close the other six families.

## Method fixed before measurement

First reuse accepted numerical evidence. The smaller C_CI validation already
contains full native roots and independent fixed-geometry path controls; A_CI
has a staged-to-native full-point link; A_PC retains both read-error bounds.
Extract those observations and compute exact rational ratios. No new numerical
diagnostic or trajectory is needed for these bounded mechanism questions.

For the performance review, reuse native cold/warm profiles and existing generic
grid comparisons, preserving their epochs and measured scope. New measurement
is limited to metadata: the actual small C_CI and large A_PC pre/post-event
graphs and one K4 payload per size, with fresh validation, default memo retention and the
existing explicit worker-local 8×4 MiB memo. Time two identical calls per case,
compare identities, then test a changed matrix entry and an invalid Boolean.
These calls exercise production graph/envelope and identity entry points; they
are not new event or trajectory executions. No cache implementation changes.

Use coarse named-call timers for one first-group 8.6 status call, a warm repeat, and selected A_PC source
retrieval. Report overlapping inclusive times explicitly; process/import/OS warmth
must not be called a new semantic cache hit. Retained authentication must still
read/check source bytes. Bound this metadata measurement to 240 seconds and
retain compact timing/counter summaries only. An interrupted measurement is
not scientific failure or a completed performance result.

No new cache is proposed merely because repetition exists. Review complete
keys, ownership, limits, invalidation and existing parity/rejection pressure;
leave any unified public-operation optimization with Tranche 9's actual callers.

## Measurement adjustment

The first 240-second metadata attempt completed no retained report. It retained
no failed-session artifact and supports no timing conclusion. The narrowed
successor drops repeated post-event K4 cases, preserves both graph topologies,
and replaces whole-call profiling with coarse authentication, decompression,
canonicalization and JSON timers. The cap and numerical non-execution scope
remain unchanged.

## Scope and closure rule

The intended population remains A_OS, C_OS, A_CI, C_CI, A_PC, C_PC,
A_CI_PC, C_CI_PC, A_RG2b and C_RG2b. The subject is the specified nine-port
mechanical specialization: ordinary evolution, fresh candidate detection,
request-driven D11-G9 expansion, target reconstruction and continuation,
coarse/Split, lifecycle and exact disabled compatibility. General autonomous
request selection, completed sparks and hierarchy remain outside this scope.

For each family, the mathematical package must identify a nonempty domain,
complete source/target and backend preimages, candidate/history policy,
realization-specific admission bounds, independent expected results, both
current/reset roles and a positive-duration continuation interval or declared
finite horizon. Separate arbitrary-size combinatorial correctness from the
numerical graphs/capacities for which those bounds actually hold. A zero-time
read, zero-current equilibrium or a boundary failure alone is not a positive
mechanical-continuation witness. Turning off the defining geometry/carrier
effects only supplies a control, not closure of an enabled realization.

The output is an **implementation-ready research construction at a declared
scope**, not ten native models. Complete profile/backend preimages here mean
the exact mathematical inputs, policies, intended identities and independent
expectations needed to implement the selected cases. They do not require
production registration, a public facade, integrated backend serialization,
or a native acceptance campaign before P9-8.1a. Bounded numerical feasibility
still belongs here: the selected arithmetic must resolve the defining effects
and required admission margins, not merely approximate an exact-real formula.

Reuse the accepted generic equations and D11-G9 allocator. Reuse accepted
proofs with an explicit check of their hypotheses on the new graph/domain;
do not reproduce the ATC discovery program or import its auxiliary potentials
as native authority. Local research code may evaluate existing primitives or
build independent oracles, but must not create/modify production substrate
or legacy code. New results remain unadmitted research until reviewed.

Each row receives one of these dispositions with linked evidence:

- **Provisionally closed:** the declared construction/domain and independent
  expectations support implementation; numerical runtime conformance is later.
- **Conditionally closed:** sufficient results exist under an explicit
  restriction awaiting user acceptance. This is not a substitute for an
  unproved hypothesis or an unknown domain.
- **Unresolved:** a named proof, oracle or contract is missing.
- **Incompatible with the selected binding:** a proved obstruction applies
  to that binding; it does not reject the whole realization.

Production entry requires all ten rows provisionally closed (including any
explicitly accepted restrictions) and user review of the aggregate scope.
Otherwise resolve the obstruction or obtain an explicit scope decision;
never silently drop a profile. Construction research can proceed independently
across rows while production remains held. No new machine gate or acceptance
schema is introduced: historical tool eligibility for P9-8.1a is unchanged
but is not sufficient permission under this current user-directed hold.

### Existing RG2b completion excludes every prescribed zero core

The current `RG2bDomain` and its graph-domain subclass require

$$0 < r_{\mathrm{inner}} < r_{\mathrm{core}} < r_{\mathrm{outer}} < c_C.$$

A section query requires every resource coordinate to satisfy
$|C_i-c_C|\le r_{\mathrm{core}}$. For a prescribed target core $C_i=0$,
$|0-c_C|=c_C>r_{\mathrm{core}}$. It is also outside the outer chart.
This is an exact exclusion for this completion family, not a tolerance issue
or a failure to choose sufficiently small time steps. It applies to both
A_RG2b and C_RG2b and cannot be removed by parameter tuning that preserves
the domain inequalities.

Sources: [`RG2bDomain`](../../../src/pygrc/models/grc_v4_rg2b.py) and
[`RG2bGraphDomain` and `section`](../../../src/pygrc/models/grc_v4_rg2b_graph.py).
The retained test checks both pinned generic declarations and confirms that
enlarging this same outer chart through zero is rejected. It is a domain
exclusion test, not an executed GRC9V4 event or section solve.

Required resolution: construct a separately identified boundary-compatible
completion, with the existing theorem's containment, inversion and contraction
hypotheses proved for the actual target, if possible. The generic RG2b contract
already allows completion-relative results; this need not change the substrate
law. If the required construction changes accepted authority, route only that
contract through investigation/claims → paper/spec before implementation.

### Fixing the selector cutoff does not establish continuation

The earlier tests retain the frozen C_OS reference cutoff collision. A second,
independent calculation checks the stronger continuation requirement. Consider
the D30 target resource/edge layout, old weights 1, internal bond weight $b$,
core 0, satellites $p_b S$ and all exterior resources 0, with $S>0$ and
$\sum_b p_b=1$. At reference geometry, zero site derivative, no causal
feedback and (for C) $\kappa_{M,C}=0$, both candidate baselines reduce to

$$J_0=-\eta\kappa\,\operatorname{Diag}(w)B^\top L_w C,
\qquad \dot C=-BJ_0=\eta\kappa L_w^2C.$$

Here $\kappa$ denotes $\kappa_c$ for A or $\kappa_{\Phi,C}$ for C. The
core rate is

$$\dot C_{\mathrm{core}}=-\eta\kappa b(4b+3)S.$$

Thus for positive $\eta,\kappa,b,S$, every positive exact-real Euler duration
produces negative core resource. With the frozen layout's $b=2,S=3$,
$(L_w^2C)_{\mathrm{core}}=-66$. Charge conservation still holds; it does not
imply nonnegative resource admission. Smaller time steps cannot repair the
sign at a zero coordinate. This is a reference/control counterexample, **not
evaluation of the frozen feedback-enabled C_OS declaration or a theorem that
all realizations fail**.

The exact rational test also retains a distinct positive control: bond weight
1, exterior resource 3 at each node, the same satellite resources and zero
core yield core rate 6 and strictly positive resources after a duration
1/128 when $\eta\kappa=1$. This is one reference-baseline continuation, not
a newly selected complete profile, source-trigger proof or all-ten closure.
Both findings require the real enabled family to demonstrate its own
boundary-viability and continuation margins rather than borrowing a control.

# P9-8.4h C_OS — native baseline entry

This successor consumes the unchanged two-beat declaration and staged oracle.
It does not change the source, shares, timestep, laws, tolerances or precision.
Select FLINT and `certified_arb_256_weighted_v1` explicitly, with no fallback.

Execute in independently retained segments:

1. `prefix`: two actual ordinary source steps; compare beat one with the
   accepted native poststate and beat two with the staged oracle. Check reset,
   chronology, non-persistence of OS geometry, final-C reconstruction and
   literal continuity. Preserve the first-beat no-event control.
2. `event`: construct the native owner from that executed source, reject a stale
   request with exact checkpoint rollback, then commit the fresh beat-two event.
   Observe, without replacing, the production source/target current/reset OS
   admissions while the old publication remains live. Compare the actual graph,
   profile and both transferred histories against the independent declaration.
3. `current` and `reset`: one actual target step per role, from the committed
   event state, including production final-C admission. Compare the selected
   current and literal resources exactly with the corresponding certified first
   step; independently compare predictor/corrector/final read vectors using the
   pre-existing dense equations (absolute/relative tolerance 2e-11).

These are baseline-entry segments, not the complete ten-step campaign. Retain
their exact input/output identities so the remaining nine steps per role can
continue from the executed poststates without replaying this work. Detached
continuation is not a public model step/reset facade. Larger covariance,
ten-step completion, event replay pressure and acceptance remain separate.

Runtime caps: 900 seconds for prefix, 1,200 for event, 600 for either one-step
role; at most two role workers, one BLAS/OpenMP thread each. An explicit timeout
or failure is retained as such, not success. Preserve completed segments; do not
overwrite or silently retry. Per-segment budgets: 12 MB raw, 2 MB compressed.
Retain XZ JSON, no logs with local paths and no duplicated full stage matrices.
Record stage vectors and geometry digests; retain the actual authoritative
poststate/checkpoint once per segment for reproducible continuation.

The read-only checker authenticates bindings, identities, role/clock/continuity
and receipt structure; it does not rerun native numerical admission. Native run
and retained integrity must never be presented as interchangeable checks.

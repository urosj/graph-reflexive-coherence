## Paper equations and independent proof

The [paper §§10.6.1–10.6.5](../../investigations/grc9v4-constitutive-design/drafts/2026-09-GRC-V4.md),
[CI+PC contract](../../../specs/grc-v4-spec.md) and
[GRC-9-V4 lifecycle contract](../../../specs/grc-9-v4-spec.md)
require a joint root with old carrier held fixed and the same selected source
used in both geometry and the subsequent carrier writer. For incoming C/W/Z:

```
D = B^T B; d = B^T C
J0(H) = -diag(W) D [diag(W)+(H-I)/2] d
G = G_W(C, W, J0(H)); q = (W-G)/(W+G)
J(H) = J0(H)/(1-q/32)
f(H) = H^-1 diag(q) J(H)/16
S(H) = (A_star .* f(H) f(H)^T)/2
H = I + kappa_H [Z_old + S(H)]
C_next = C - dt B J
W_next = logarithmic_writer(C_next, W_incoming, J_selected)
Z_next = exp(-dt) Z_old + [1-exp(-dt)] S_selected
```

Incoming-C/W fixed row descriptors and G are evaluated at each trial H;
conductance is never frozen at the reference trial. No writer runs inside
the root. Target Z=0 removes old history, but leaves an instantaneous source
and nonidentity geometry. PC substitution is therefore a genuine negative.

The point producer uses a private 100-digit mpmath context and literal A
read/write equations shared with the accepted A_OS research producer. Its
research iteration stops below `1e-75` with a cap of 128; this is distinct
from the intended native recipe. A separate interval evaluator bounds the
root and both writers. Native current/root/writer/row-evaluator and allocator
entry points are disabled while the test rebuilds the oracle byte for byte.
Structural and codec helpers validate identity only; a separate mechanical
comparison checks the independently constructed D52 topology and candidates.

The uniform proof covers every C/W/Z and every H in the declared charts.
Each fixed row is a positive-weight convex average of neighbor differences,
so its component is at most `sqrt(2)*M` and the descriptor norm at most
`sqrt(6)*M`, including empty rows. Let `b2 >= ||D||2`, `b1 >= ||B^T||2`,
using outward bounds `sqrt(||A||1 ||A||inf)`. Then:

```
J0_bound = w_max b2 (w_max+rho/2) b1 M
L0 = w_max b2 b1 M/2
m = 31/32; J_bound = J0_bound/m
Lq = 2^-25 J0_bound L0
LJ = L0/m + J0_bound Lq/(32 m^2)
f_bound = J_bound/[16(1-rho)]
Lf = {J_bound/(1-rho)^2 + (Lq J_bound+LJ)/(1-rho)}/16
S_bound = f_bound^2/2
root_contraction <= |kappa_H| f_bound Lf
root_displacement <= |kappa_H| (R+S_bound)
```

`33/31`. The conductance exponent is bounded by
`[sqrt(2)M+(2 sqrt(6)M)^2+J_bound^2]/2^25 < 1/2`.
Thus `exp(-1/2)>1/2` keeps the conductance floor inactive throughout the
chart and justifies the smooth contrast derivative bound. The star mask is
nonexpansive in Frobenius norm. All displayed inequalities are backed by

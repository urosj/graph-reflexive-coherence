## Reproduction

From the repository root, use `.venv/bin/python`,
`PYTHONPATH=src:.:tests:implementation/phase-9-grcv4/verification`,
`OPENBLAS_NUM_THREADS=1` and `OMP_NUM_THREADS=1`.

- `p984h_apc.py check` checks the retained source; `run` executes it and refuses
  overwrite. It authenticates the historical prerequisite at its exact Git
  epoch and binds all current execution sources separately.
- `p984h_apc_campaign.py check --segment event` checks the actual event.
  `chain --role current` and `chain --role reset` execute or verify each
  ten-step chain followed by its final read. Existing successful segments are
  checked, never silently overwritten.
- `p984h_apc_covariance.py run --kind KIND` executes one event and both short
  histories. Run all eight kinds in parallel, one thread per worker:
  `edge_order`, `node_order`, `relabel`, `signed`, `combined`, `rotate`,
  `rotate_twice`, `reflect`. Every worker has its fixed event/step cap.
- Selected CLI/API/notebook/browser status authenticates the retained roster
  without numerical execution. Use `tranche8_evidence status --family A_PC
  --checkpoint 8.4h`. The separate small browser projection supplements the
  preceding full index; it does not assert a full-boundary pass.

The [retained closeout](./P9-8.4h-APCCloseout.json) passes all nine immutable event checkpoints in

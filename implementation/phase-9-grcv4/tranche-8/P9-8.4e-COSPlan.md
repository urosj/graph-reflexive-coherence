# P9-8.4e C_OS ordering and signed covariance

This bounded campaign tests the frozen source-edge-order permutation and four
additional transformations through native C_OS source evolution, expansion,
both-role target admission, two continuation steps per role and a fresh final
read. It does not rerun the ten-step depth campaign or claim arbitrary graphs.

Use the accepted D52 positive-chirality phase-1 allocation and D94
negative-chirality phase-3 allocation unchanged. For each layout execute a base
and five variants: reversed edge order (the frozen vector), reversed node
order, injective node/edge relabeling, alternating boundary-edge reorientation,
and their composition. Thus twelve events yield twenty covariance history
cells, forty-eight target steps and twenty-four final reads. Source evolution
is shared across the two layouts, but not inferred between transformations.

The signed permutation S transports J and Read-Back as Sx and geometry as
S H S^T; vertex permutation P transports C. Stable edge-keyed reference weights
are relabeled, not signed. C_OS has neither W_A nor Z_4: this work earns no
unsigned-A-history or persistent-carrier evidence. Event namespaces change
with source identity; compare transported typed labels, ports, kinds and
orientations exactly, not raw digest equality. Chart/phase/chirality changes
belong to P9-8.4f, not this campaign.

Keep the predecessor componentwise comparison budget (absolute and relative
2e-13). Reuse the existing dense equations and captured-consumer checker;
these are bounded cross-checks, not rigorous full-error certificates. Compare
both predictor and corrector currents, Read-Back, generated H, written C and
fresh final reads. Recompute the independent dense trajectory from the
independently transported target, not from native poststates. Check both-role
admission before publication and exact checkpoint replay.

transport, stale edge-keyed reference, stale request identity and mutated
coverage. Distinguish covariance-comparator rejection from native admission

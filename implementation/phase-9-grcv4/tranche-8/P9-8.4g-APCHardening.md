## Derivation and preserved exclusion

The [plan](./P9-8.4g-APCHardeningPlan.md) derives the leading sensitivity proxy
`s^5 ((1-s)/(1+s))^2`. Its unconstrained sixteenth-grid optimum, 11/16, was
infeasible: both target roles have negative core and extra/3/1 resources. Exact
full-law interval exclusions are retained. This is a mixed inherited-history /
unit-new-edge-seed resource imbalance, not a numerical solver defect.

Deriving all ten empty-node baseline-rate polynomials before selecting again
gives the constrained grid maximizer **s=7/8**. Full-law checks then establish
positivity, both writers and final reads. Old-edge history is inherited at this
scale, retaining the signed role contrasts; every new edge still has seed 1.
Both source carriers, resources, shares (1/4,3/8,3/8), profile parameters,
dt=2^-12, tolerances and arithmetic policies are unchanged. Target Z starts at
zero and is created solely by the lawful held-source writer. No target carrier
is injected to force a visible effect.

companion, not a uniform parameter domain or whole-trajectory error bound.

falsely identify changed histories as the old scientific state is removed.

executed event identity. Actual postbeat requests, both-role transfer and target

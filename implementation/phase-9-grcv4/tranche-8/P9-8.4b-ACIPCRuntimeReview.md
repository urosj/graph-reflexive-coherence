between incoming W and conductance G(C,W,J0). The independent equations are

```text
J0 = -M D (M + (H-I)/2) B^T C
q = (W-G(C,W,J0))/(W+G(C,W,J0))
J = diag(1-q/32)^-1 J0
Read-Back = diag(q/16) J
flat = H^-1 Read-Back
S = star_mask * outer(flat,flat)/2
H = I + 2^-15 (old_Z + S)
C_next = C - dt B J
W_next = exp(a log(W) + (1-a) log(G(C_next,W,J)))
Z_next = a old_Z + (1-a) S,  a = exp(-dt)
```

The first C implementation reused the RG fixed-H kernel verbatim. It passed

The successor keeps parameters, states, carrier seeds and the strict gate
unchanged. It uses compensated dot products for the C baseline and the exact
response identity below. Put `T=I+t H D`, `R_f=T^-1`, `p=zeta_C chi_C`.
Instead of forming `R_f` and solving the nearly identity total-current block,
solve

$$
(T-pI)u=J_0,\qquad J=J_0+pu,\qquad j_{\rm causal}=\chi_Cu.
$$

Indeed, `T u=J_0+p u=J`, so `u=R_f J` and
`(I-pR_f)J=J_0`. The accepted current inverse margins imply invertibility.
No commutation of D and H is assumed; the regression includes a noncommuting
target geometry. The C baseline is evaluated as
`-t * product(D, product(H, B^T C))`, with each product using rounded scalar
products and `math.fsum`. The small feedback correction is added to J0 once.

The independent interval kernel retains its original response/inverse
formulation, providing a separate check of the transformed equation and its

ratio to about **1.342**, and the corresponding CI+PC ratio to about **1.289**.
It changes arithmetic evaluation order, not the constitutive law, precision,
tolerances or declared physical inputs. OS and RG owners remain unchanged.

## Root and full-output certificate

For fixed incoming C/W and, where present, **fixed old Z**, define

$$
T_{\rm CI}(H)=I+\kappa_H S(C,W,H),\qquad
T_{\rm CI+PC}(H)=I+\kappa_H[Z+S(C,W,H)].
$$

Use the accepted geometry-ball bounds, freshly evaluated on each actual input
enclosure, to verify current regularity, source Frobenius norm `<R`, strict
geometry image containment and `q=kappa_H Lip_H(S)<1`. The full source matrix
aggregation and full coordinate-hull guards from the reviewed mathematical
owner are reused. Z is held fixed in the root and does not add a second source
derivative or extra q factor.

Four represented fixed-point updates produce a trial H. The verifier then
recomputes the **entire** interval root image at that returned H and bounds

$$
r=\|\widehat H-T(\widehat H)\|_\infty,\qquad
\|\widehat H-H_*\|_\infty\le e_H=\frac r{1-q}<2^{-48}.
$$

The root exists and is unique in the declared ball by the separately verified
image/contraction hypotheses. Four updates alone confer no acceptance; the
returned-point residual is controlling. An interval image centered at
`T(Hhat)` with padding `q e_H` encloses the true root. Disjoint entries remain
zero. This refinement separates represented identity-diagonal rounding from
uncertainty in the exact root; no residual or coordinate is discarded.

PC has the exact old-carrier geometry `H=I+kappa_H Z`: it uses q=0 and the
directly enclosed image, with represented assembly error measured against it.
All represented geometries must satisfy symmetry, support and the geometry
ball independently of their residuals. Input carrier enclosures must satisfy

## Reproduction and storage

Use the repository `.venv` and `PYTHONPATH=src:implementation/phase-9-grcv4/verification`.
Set `OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1` for native runs.
`p984h_cos_native.py check --segment prefix` checks retained prefix integrity
without numerical execution. Its `run` action executes native code and refuses
to overwrite evidence.

For event/role segments, `p984h_cos_native_compact.py run event` (or `current`,
`reset`) explicitly selects compact JSON inside XZ. The same bound scientific
functions and caps run unchanged. The driver records its own source identity.
The checkpoint's pretty-printed form would exceed the raw budget; compact JSON
preserves every field and avoids that formatting overhead. `check event`
also validates receipt/commit/lifecycle identities, without numerical replay.
Do not present retained identity checking as re-execution.

After numerical-source changes, original direct check commands intentionally
detect source drift. The side-tool authenticates the named superseded sources
against Git `718f95be`, preserving original execution identities. Current-code
conformance requires separately bound execution, not this historical adapter.
See [solve-reuse measurement](./P9-8.4h-COSPerformance.md).

## OS split admission

The [OS contract](../../../specs/grc-v4-spec.md#realization-contracts) requires
a predictor, one fresh corrector, and a split-residual decision. The existing
[`OSSplitResidual`](../../../src/pygrc/models/grc_v4_realizations.py) implements
`edge_l2_v1` as

$$\left\|H_{\rm ref}^{-1/2}D H_{\rm ref}^{-1/2}\right\|_2\le\tau,
\qquad D=H_p-H_{\rm regenerated}.$$

For symmetric D and admitted positive-definite reference geometry, this is
equivalent to both $\tau H_{\rm ref}+D$ and $\tau H_{\rm ref}-D$ being positive
semidefinite. The checker independently uses exact rational Schur tests on
the represented operands, including equality, rather than rounded residual
entries or a floating eigensolver. Tests also include a nonidentity reference
where the raw norm passes but the normalized norm fails.

Here $H_{\rm ref}=I$, so the previous Frobenius bound directly bounds the
required spectral norm:

$$\|D\|_2\le\|D\|_F\le q_h\kappa_Hs.$$

Select the **proposed research** OS declaration:

| Field | Value |
| --- | --- |
| Predictor | `reference_geometry_predictor_v1` |
| Corrector | `one_fresh_geometry_corrector_v1` |
| Split norm | `edge_l2_v1` |
| Tolerance | $\tau=2^{-40}\simeq9.095\times10^{-13}$ |

The exact A and C ceilings, approximately $8.224\times10^{-17}$ and
$4.892\times10^{-15}$, are each **less than $\tau/128$**. This proves the
exact-real split inequality over the earlier declared physical chart and
sixteen layouts. It does not prove a uniform arithmetic-error budget over
that chart. The represented runs below decide their own split inequalities
exactly, rather than assuming numerical error fits the unused margin.

This tolerance is separate from linear-solver error and from the minimum
resolvable constitutive effect. Increasing it cannot restore a lost effect.
No existing complete profile or tolerance is changed.

## Represented arithmetic and controls

The [new checker](../verification/test_p980_os_numerical_feasibility.py) uses
an independent staged binary64 evaluator. Products round to binary64;
`math.fsum` accumulates scalar products; Python `math` supplies exp/log/tanh;
mpmath's binary64 `fp` context supplies LU solves. NumPy stores arrays but
does not supply BLAS reductions or linear solves. Constants and incoming
resources are rounded at entry; intermediate H, currents, drives and history
are represented during evaluation, not merely at publication.

C uses the already-proved physical response $(I+tHB^TB)^{-1}$, while the
70-digit predecessor oracle retains the full normative similarity. This is a
declared research arithmetic binding, **not an execution of the native solver
or a promise of bit-identical libm behavior on every machine**. No future
production precision or backend is selected by this experiment.

For each represented current block $Ax=b$, the checker independently computes
the exact dyadic residual and the bound

$$\|x-\widehat x\|_\infty\le
\frac{\|A\widehat x-b\|_\infty}{1-\|I-A\|_\infty}.$$

The denominator is verified positive. This encloses error relative to the
**represented current block**, not coefficient construction, C's preceding
response solve, libm error or the full exact-real law. A scalar control checks
the enclosure against the exact solution and detects a corrupted result.
Small block error is not used to certify mechanism survival.

Additional controls prevent mistaking an omitted consumer for rounding loss:

- A supported non-diagonal H perturbation within the reviewed chart produces
  baseline/current changes larger than $10^{-9}$ in both candidates, agreeing
  with the independent high-precision geometry effect within $10^{-13}$.
  This is a supplied-H control, not generated-geometry evidence.
- A whole source OS step is compared with the independent 70-digit evaluator
  on identical represented inputs. That evaluator still has nonzero generated
  geometry and predictor/corrector differences. Its A writer also distinguishes
  selected current from baseline current. These numerical comparisons are
  not outward interval certificates.
- Read-Back-off, geometry-potential-off and C modulation-off controls are
  evaluated on the actual witness; the actual A history output and fresh/stale
  writer operands are compared separately.

### Review bound on the old writer

For matched writes with identical final C and incoming W, only the current
operand changes. With $\theta=\zeta_A\chi_Aw/(1-w)$, the old diagonal solve
and $|J_0|\le1024$ give

$$|J^2-J_0^2|\le1024^2[(1-\theta)^{-2}-1].$$

The other exponent terms cancel, the floor is inactive, and the logarithmic
writer multiplies the difference by $1-e^{-d}\le d$. The exponential mean
value bound is at most $1+w$ along the interval between the two log histories.
Consequently

$$|W^+(J)-W^+(J_0)|\le
(1+w)d\frac{\gamma\,1024^2}{2}[(1-\theta)^{-2}-1]
<1.695\times10^{-21}.$$

The exact rational checker evaluates approximately $1.6940661012\times10^{-21}$,
only $1.526\times10^{-5}$ of the minimum local binary64 spacing $2^{-53}$.
Changing resource states within the old bounds cannot produce a robust
one-ULP exact writer-output margin. This is **not** a proof that every pair
rounds identically: arbitrarily close values may straddle a rounding boundary.
Nor does ordinary nonzero W evolution establish sensitivity to the chosen
current operand. This bound rules out a resource-only search in the old chart.

### Separate successor

The [effect-witness successor](./P9-8.0-OSEffectWitness.md) changes sensitivities
and history amplitude in a separately identified OS research construction,
keeping topology and binary64 arithmetic. It tests actual returned history,
its subsequent current consumer and combined whole-evaluation error margins.
It does not overwrite this regression or the old all-realization bounds.

The OS raw-to-normalized mapping and proposed tolerance are now explicit,
with exact-real chart bounds and exact admission checks for the represented
cases. **Represented mechanism survival remains open.** In particular, this
binary64 witness cannot discriminate removing the geometry potential consumer
or substituting baseline current in the A writer, although the earlier
high-precision F1 tests can. A passing regression test records that limitation;
it is not a positive conformance verdict for those mechanisms.

Do not require every infinitesimal effect to survive at every state, or every
realization to differ at every step. Require a bounded enabled numerical
witness that genuinely discriminates the defining consumers and writers.
The separate successor now proposes a less degenerate parameter/domain witness
with new local interval bounds and full-effect margins; review it before
reuse or return to RG2b. This original checkpoint does not select revised
native profiles or precision. Merely tightening the linear solver, widening
the split tolerance or borrowing the small ATC example does not resolve the
finding.

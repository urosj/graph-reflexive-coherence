## CI-only tree23 certificate

The successor is
[`p984d_cci_certificate.py`](../verification/p984d_cci_certificate.py).
It reuses the accepted interval full-formula evaluator and inverse arithmetic,
but explicitly re-establishes the dimension-sensitive premises. Native
evaluation is not used to construct the independent interval expectations.

For a connected unit graph on N vertices, the reference Laplacian gap is at
least `2/[N(N-1)]`. This follows by bounding a maximum-to-minimum path's energy
by the total graph energy and bounding the centered squared norm by N times
the squared range divided by four; the stated bound is conservative. For
the symmetric star-supported ball `||H-I||_infinity <= rho=2^-20 < 1/2`,
the nonzero gap is therefore strictly greater than `1/[N(N-1)]`. At N=23,
`1/506 > Lambda_C=1/512`; the constant selector remains isolated throughout
the ball. The checker explicitly requires a connected simple tree with unique
vertices/edges, N<=23. N=24 is outside this certificate, not claimed impossible.
The fixed profile has unit transport references, unit reference geometry and
unchanged cutoff; frozen input bindings supply those hypotheses.

The C response is `R=(I+t H D)^-1`, where `D=B^T B` and t is the fixed
resource-dependent modulation. The interval box encloses the entire supported
geometry ball. With `theta=zeta*chi*||R||_infinity < 1/2`, the same accepted
derivative inequalities bound the baseline, response, current, lowered read
and structural-source Lipschitz constants. Norms of D, R and the support mask
are computed for the actual graph, not inherited dimension constants. The
checker requires `kappa_H*||S||_infinity < rho` and
`q=kappa_H*Lip(S) < 1`, and independently checks the complete sum of squared
source entries against the unchanged source ceiling.

This is CI only: there is no carrier. In particular, the old PC/CI+PC
conversion `sqrt(m)<=4` is **not** reused for 22 edges. No PC image or carrier
closure follows from this certificate.

For each saved represented H, the full interval residual gives
`root_error <= ||H-(I+kappa_H*S(H))||_infinity/(1-q)`.
One exact image plus `q*root_error` encloses the joint root geometry; the
full current and source equations are evaluated over that enclosure. The
old ceilings remain: root error `<2^-48`, current/baseline error `<2^-40`,
source error `<2^-64`, and resource output error `<2^-40`. The existing
consumer separately checks same-root Read-Back/source/generated geometry,
native domain identity, both-role admission, represented continuity and
fresh final-root equality. On <=17 vertices the historical independent
checker is used unchanged, including the reused source evidence.

These are pointwise full-formula error enclosures at actual represented
prestates, not an accumulated exact-real trajectory tube. In particular,
positive stored resource values smaller than an absolute error ceiling are
not automatically a proof of exact-real positivity. The independent nominal
ten-step trajectory is a separate comparison, not such a tube.

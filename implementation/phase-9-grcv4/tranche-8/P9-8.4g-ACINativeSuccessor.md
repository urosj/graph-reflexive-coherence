No physical current is substituted, and there is no fallback or precision retry.

image, exponential and positive conductance floor. The zero-crossing square
includes zero; signed intervals and floor crossings retain both endpoint bounds.
A very negative lower exponential tail is bounded before flooring, not used
to discard the upper tail. Physical staging, history writing, root tolerance,
declared domain and the fixed-row two-consecutive-pass rule are unchanged.

The original conservative-widening counterexample now passes its inclusion
assertion. Four focused new tests plus seven existing interval tests pass,
including exact parity, signed/zero-crossing and underflow/floor boundaries,
singular/inconclusive failure and no exact-inverse fallback. All 86 generic
CI/CIPC tests also pass. These are bounded regression results, not evidence
that every possible profile/graph or boundary case has been exhausted.

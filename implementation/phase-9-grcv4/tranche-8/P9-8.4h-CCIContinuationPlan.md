# P9-8.4h C_CI — actual-target continuation

This successor preserves the source/event package unchanged. It consumes the
published target checkpoint in `P9-8.4h-CCI-event.json.xz`, not the old prepared
target. Run ten ordinary steps independently for each target role, then one
fresh final joint root per role. Both histories keep the actual target reset;
the reset-role trajectory changes current, not reset, during continuation.

Reuse the accepted CI full joint-residual checker and contraction/error bridge.
For each step, check reset, current and final-C roots, their selected geometry,
domain/certificate identity, and literal represented continuity. Check clocks,
no carrier/history writes, reset preservation, represented charge admission and
exact stored-charge drift. Bound the exact-root next resource from each actual
represented input using `dt * ||B_i||_2 * current_error_upper`; retain rounding
error separately. Require positive enclosure lower endpoints and positive
represented resources. These are local per-step bounds, not a uniform global
trajectory enclosure or an above-rounding feedback-effect certificate.

The first-pass/reference-geometry assumption is checked at every root, never
imposed. A different root, inconclusive sign, or admission failure stops the
affected run explicitly. No clipping, changed tolerances, fallback or retry.
Use FLINT with `certified_arb_256_weighted_v1`, one numerical thread per worker,
at most two role workers, and a 600-second cap per step/final root. Same dt,
CI domain and tolerance as the event. No new source step or event execution.

`verification/p984h_cci_continuation.py prepare` authenticates the event once;
`run --role current` and `run --role reset` execute resumable successful chains.
`check` checks retained records, never reruns a native root. Native runs also
perform the retained scalar/linkage checks before saving each step. XZ records
have a 2 MB compressed per-segment cap; partial failed-session dumps are not
retained. All paths are repository-relative.

After this batch, the already specified eight one-event/two-step covariance
counterparts and final coverage review remain. This batch does not accept C_CI,
close aggregate .h, or add any G2/G3 support.

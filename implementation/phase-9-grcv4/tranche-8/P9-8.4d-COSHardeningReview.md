## What the sign enclosure proves

Each exact-real OS evaluation starts from the actual saved represented
prestate. For the connected unit tree, the nonconstant reference spectral
gap is at least $2/[N(N-1)]$. The bound

$$
(1-\lVert H-I\rVert_\infty)\frac{2}{N(N-1)}>\Lambda_C>0
$$

certifies that the selector is precisely the constant projector, separately
at predictor and generated corrector geometry. Thus the sector is the mean
resource and $H_M=tH$, with
$t=\exp(\kappa_{M,C}\tanh(\bar C/C_{\rm ref}))$. The flux response becomes

$$
F=(I+\tau_C tH B^\mathsf{T}B)^{-1},\qquad
J=(I-\zeta_C\chi_CF)^{-1}J_0.
$$

The evaluator encloses the nonlinear modulation, both inverses, generated
geometry, corrector current and continuity. It verifies a strict current
contraction bound before using the inverse. Arb endpoint bounds and the
native stored values yield per-coordinate error bounds. Every coordinate
must have an exact-real lower bound greater than that error bound. Literal
binary64 continuity from the captured native current must also reproduce the
stored resource exactly.

This separates mathematical positivity from represented positivity for these
particular updates. It is not an accumulated exact-trajectory enclosure, a
uniform neighborhood certificate, or an error bound for every possible
machine execution. The remaining eight steps retain the original dense
comparison scope.

## Reproduction and retention

From the repository root, first restore existing evidence with
`.venv/bin/python scripts/evidence_storage.py restore`.
Set `PYTHONPATH=src:.:implementation/phase-9-grcv4/verification` and run
`.venv/bin/python implementation/phase-9-grcv4/verification/p984d_cos_hardening.py`:

- `prepare` freezes the declared checks and source bindings.
- `run` executes this supplement only and refuses to replace a completed result.
- `check` authenticates retained bindings, subjects and result structure.
- `recheck` also recomputes interval signs and finite dense probes, not native
  trajectories. It is repeatability, not another independent audit.

The small result retains interval bounds, failure details, receipt comparisons
and neighborhood minima. Original operands remain in the byte-exact original
archive; no duplicate trajectory dump is needed. Neither this supplement nor
its checks grant user acceptance or all-family closure.

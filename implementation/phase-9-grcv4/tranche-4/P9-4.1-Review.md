`CandidateCTransport` accepts only a typed graph and complete Candidate C
profile. The profile owns the immutable map; there is no state, history,
geometry, selector, cache, or ordinary-step writer input. Target edge coverage
must be exact. The frozen candidate schema requires a nonempty map, so an
edgeless target rejects; this leaf does not expand that admitted domain.
The output Hodge is the reference Hodge, not a generated or
retained stage Hodge. A new target graph needs an explicitly complete target
profile; this local check does not execute an event or its atomic commit.

Three identities have different purposes: operator identities identify the
primitive operators; constructor identities bind the typed policy, units,
transport law, graph coordinates and map identity (plus eta for mobility);
the complete binding identity also includes the complete profile. Eta changes
only the mobility constructor. Unrelated selector/geometry controls change the
complete binding without changing either constructor. A units declaration can
change both constructor identities while leaving their numeric matrices equal.
No unit conversion or admission of an unknown execution policy is inferred.

The internal reconstruction record contains only graph and complete profile.
Both outputs are rebuilt and validated. It adds no public snapshot schema;
extra derived arrays, state/history fields, duplicate JSON keys and stale
profile/map identities reject. Binary64 positivity is inherited without a
floor: positive representable subnormal products are retained; overflow and
products rounded to zero reject. No conditioning claim follows from positivity.

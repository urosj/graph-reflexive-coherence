For the implemented unit-H0, constant-zero-context, zero-V' declaration, fix the
graph and complete reference profile. With H the supplied structural Hodge,
P its strict-gap projector, T = PC, endpoint average A, D the diagonal deformation,
and M = eta Diag(W_C_tr), the tested chain is:

```text
delta_T   = delta_P C + P delta_C
delta_rho = sech²(T/C_ref) delta_T / C_ref
delta_D   = (kappa_M/2) D Diag(A delta_rho)
delta_Hm  = delta_D H D + D delta_H D + D H delta_D
delta_Phi = kappa_Phi B delta_Hm B^T C
            + kappa_Phi B Hm B^T delta_C
delta_J0  = -M B^T delta_Phi
```

The spectral-projector oracle uses the selected/unselected divided difference
`(s_i-s_j)/(lambda_i-lambda_j)` applied to `V^T B delta_H B^T V`.
It never divides within a selected or unselected cluster. Repeated eigenvalues
inside a cluster therefore remain admissible; a closing cross-cluster gap raises
sensitivity and an unresolved gap or crossing does not establish a derivative.
An exact three-node path projector and its literal derivative independently anchor
this formula, beyond comparisons that share NumPy eigendecomposition.

This is the complete baseline derivative for the supported declarations:
V'' and delta_U vanish by the declared evaluator/context, and delta_B = delta_M = 0
on a fixed graph/reference profile. Unknown potential/context declarations reject.
A separately labeled adjacent-profile eta study exercises the additional
`-delta_M B^T Phi` term; it is not ordinary same-profile motion or lifecycle
migration. Vertex permutations and signed edge transformations are tested as
discrete covariance of every chain output and its directional derivative, not as
a fictitious continuous delta_B direction. Fixed-stage trial J and evaluation
metadata do not enter J0.

Phi remains the constitutive frozen-Hm potential. It is **not** the total resource
gradient of `E(C) = kappa_Phi (B^T C)^T Hm(C) (B^T C)/2`.
An independent energy difference exhibits the nonzero extra chain term
`kappa_Phi (B^T C)^T delta_Hm (B^T C)/2`. Adding that term to the implemented
constitutive potential would change the specified model.

## Separate controls

Each row changes exactly one candidate parameter on the same dense nonreference
SPD structural Hodge, with nonzero retained conditioning and baseline current.
Mobility's matrix, action and constructor identity remain fixed. Its enclosing
profile-bound descriptor legitimately changes when the complete profile changes.

| Control | Required behavior |
|---|---|
| kappa_M = 0 | D = I, Hm = Hpre, while reference mobility is unchanged. The nonreference structural Hodge survives; J0 changes and Read-Back remains active. |
| chi = 0 | Hm and J0 unchanged; gated read is zero, ungated response is nonzero, J = J0. |
| zeta = 0 | Hm and J0 unchanged; J = J0 while Read-Back remains nonzero. |
| tau = 0 | Nonzero kappa_M and nontrivial Hm survive; Rhat = I and physical read = J. At chi = 1, zeta = 0.4, J = J0/0.6. Direct baseline conditioning survives. |

The tau row discharges the supplemental `P9-REVIEW-FOLLOW-7.3` obligation without
editing the frozen catalog or collapsing controls into a simultaneous-zero case.
Baseline resource/geometry derivatives are checked separately under every control.
The kappa-zero reference reduction also has a literal matrix derivative oracle.

Finite differences require fresh admitted base/plus/minus current evaluations and
a common selector rank. Most use dyadic, zero-sum resource directions; the scalar
uniform-resource derivative is explicitly an ambient constitutive sensitivity,
not a charge-preserving trajectory. The zero-resource boundary uses a second-order
forward difference because the negative point is outside the admitted domain.
Rank agreement at the sampled points is a local test guard, not a proof of global
stratum preservation along a beat.

The derivative is of the real constitutive equations, not of a map that rounds
all inputs and outputs to binary64. At scalar mean 20, tanh rounds to 1 and the
actual central current difference is zero, although a 70-digit closed formula
has a positive derivative. The oracle uses a stable exponential sech² expression.
This case establishes that a rounded zero difference must not be used as proof
of zero sensitivity; it makes no finite-difference accuracy claim at saturation.

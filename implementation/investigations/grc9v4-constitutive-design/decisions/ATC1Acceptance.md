## Four claim-local clarifications

### 1. Diagonal-reference CAN-R+ is inactive on defined nonedge diagnostics

For diagonal positive reference Hodge and distinct nonadjacent vertices,

$$
(B H_{\mathrm{ref}}B^\top)_{ab}
=\sum_e w_e B_{ae}B_{be}=0.
$$

No incidence column meets both vertices. Parallel edges do not change this;
loops, where admitted, have zero incidence. If both diagonal factors are
positive, the normalized diagnostic q_ab is zero and cannot satisfy the
strict guard q_ab > theta_q for any nonnegative theta_q. At an isolate the
normalization can instead be undefined: do not manufacture a zero or an
admitted result from a missing denominator.

This is an explicit law/read applicability restriction for CAN-R+ / assembled
CAN-A under K0's diagonal-reference OS read, not merely a fixture result.
It does not reject every OS topology law. Replacing the read by a fresh OS
pass or replacing H by its inverse would be another declared witness, not
a repair inside this accepted choice. Applies to `ATC7-CL-03`/`29A` and their
claim-local debts; no blanket OS rejection or debt closure is entered.

### 2. Present-state generation does not supply arbitrary historical crossings

If two histories share the same projection but differ on a historical
predicate, that predicate cannot be a function of the projection alone.
For example, present value 3/2 and threshold one do not distinguish previous
values 1/2 and 3/2. This is an information countermodel, not a native
reachability claim.

K0 therefore supplies no general first-crossing detector, refractory counter
or archived-sibling reversion. Existing W/Z might suffice for a particular
predicate only if that sufficiency is demonstrated. No new memory does not
mean no existing history, and historical alternatives retain their debts.
Applies to `ATC7-CL-02`/`25`; debt 03/22 activation is not globally discharged.

### 3. Duration exclusion does not imply beat-subdivision invariance

Equal eligible poststate projections under the same policy give equal physical
prescriptions. That pointwise property does not equate one full beat with
two half-beats, which create different sampling opportunities. The exact
synthetic conservative flow C(t)=(1+t,3-t), sampled with guard C0 >= 3/2,
first activates at t=1 for one unit beat and t=1/2 for half-beats.

This is not a native ATC trajectory or a defect in ordinary evolution. K0
explicitly makes no beat-subdivision, physical-time event-rate or non-Zeno
invariance claim. Such stronger claims need separate proof. Applies to
`ATC7-CL-02`/`24`/`26`; request-duration exclusion remains a pointwise rule.

### 4. A post-event-commit interruption preserves s2

The failure boundary depends on the last completed publication:

| Last completed commit | Subsequent failure or interruption | Retained state |
| --- | --- | --- |
| None | Ordinary rejection/error before publication | s0 |
| Ordinary | Event rejection/error/interruption before event publication | s1 |
| Event | Response construction/delivery interrupted after event publication | s2 |

There is no rollback from s2 to s1 merely because the response was interrupted.
This does not promise crash-durable exactly-once delivery, automatic retry or
an already implemented composite result/archive schema. The future result
must distinguish `not_eligible` from evaluated `no_event`, preserve ordinary
success, and keep scientific failures distinct from programmer exceptions.
Applies to `ATC7-CL-24`/`31` and the open composition obligations.

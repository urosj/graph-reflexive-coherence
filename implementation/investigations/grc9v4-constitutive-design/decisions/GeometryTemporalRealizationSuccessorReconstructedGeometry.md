## Purpose

This is the third realization-family pressure after the accepted
coupled/implicit and operator-split A/C constructions. It separates three
questions that must not be conflated:

```text
RG-1:
  is a same-beat reduced evaluator a distinct temporal family?

RG-2a:
  can geometry generated by an already complete CI or OS step be reconstructed
  locally from its committed poststate?

RG-2b:
  can the original lagged geometry step be closed by a fixed invariant section
  without persisting geometry?
```

RG-1 closes negatively for distinct family identity. RG-2a closes positively
as a property of the existing families. RG-2b closes positively as a genuinely
distinct bounded local realization for both A and C.

## RG-1: Same-Beat Reduced Reconstruction

For candidate `a`, define

```text
X_a,k = authoritative committed state
U_k   = declared same-step inputs and fixed constitutive profile configuration
C_a(h;X_a,k,U_k) = accepted fixed-h current solution
S_a(J,h) = accepted K_4-valued structural map.
```

The accepted current-dependent geometry relation is

```text
h = H_profile(K4_base + S_a(C_a(h;X_a,k,U_k),h)).
```

An exact evaluator `R_a(X_a,k,U_k)=h` may exist as a closed-form expression,
symbolic elimination, generated code, or exact table with algebraic provenance.
If it reproduces this fixed point exactly, it changes evaluation representation,
not temporal semantics. It is CI-equivalent.

If the evaluator freezes one or more current predictors before a later
corrector, it has operator-split semantics. A new predictor/corrector order is
a named OS successor rather than a third family.

The RG-1 dispositions remain:

```text
A same-beat distinct RG family = family_level_obstruction
C same-beat distinct RG family = family_level_obstruction
```

This is exact constitutive equivalence, not formula nonexistence and not a
general obstruction to reconstructing geometry.

## RG-2a: Existing-Family Poststate Reconstruction

For one already complete CI or OS step, write

```text
Phi_a(E) = X_a,k+1
G_a(E)   = h_a,k+.
```

Local reconstruction from committed state is possible whenever the complete
commit map is locally invertible:

```text
R_a+(X_a,k+1) = G_a(local_inverse(Phi_a)(X_a,k+1)).
```

The accepted A and C transitions provide an exact identity limit on their
smooth zero-duration extensions.

For C, with no boundary or source impulse at zero duration,

```text
Phi_C(C;0) = C
D_C Phi_C(C;0) = I.
```

For A,

```text
a_A = exp(-Delta_t/tau_A)
a_A(0) = 1
C+ = C
W_A+ = W_A,
```

so

```text
Phi_A(X;0) = X
D_X Phi_A(X;0) = I.
```

`Delta_t=0` is a smooth-extension reference boundary, not an executed
positive-duration evidence row. Continuity of the complete derivatives gives
a candidate-local `epsilon_t > 0` for which each commit map is locally
invertible when `abs(Delta_t) < epsilon_t` on the named smooth chart.

Therefore geometry generated by an already complete CI or OS transition is
locally reconstructible from its poststate. This does not create a distinct RG
architecture. It is a reconstructibility property of CI or OS.

The proof requires fixed context or a deterministically known input schedule.
An arbitrary exogenous input used in beat `k` cannot be inferred from
`X_(k+1)` unless it is included in authoritative state or declared input.

## RG-2b: Lagged Invariant-Section Architecture

The distinct reconstructed family returns to the original lagged order:

```text
X_a,k
  -> h_a,k = Gamma_a(X_a,k)
  -> J_a,k
  -> h_a,k+
  -> X_a,k+1.
```

There is no simultaneous current-geometry root, no same-beat geometry
corrector, and no serialized geometry. The generated geometry must equal the
section evaluated at the committed poststate:

```text
h_a,k+ = Gamma_a(X_a,k+1).
```

Let

```text
Psi_a,Gamma(X) = Phi_a,lag(X,Gamma(X))
G_a,kappa(X,h) = H_profile(K4_base + S_a(C_a(h;X,U),h)).
```

The exact invariance equation is

```text
Gamma_a(Phi_a,lag(X,Gamma_a(X)))
  = G_a,kappa(X,Gamma_a(X)).
```

Equivalently, define the graph transform

```text
(T_a Gamma)(X') = G_a,kappa(X,Gamma(X))
where X = inverse(Psi_a,Gamma)(X').
```

An invariant reconstruction law is a fixed section:

```text
Gamma_a = T_a Gamma_a.
```

## Local Existence Argument

At `kappa_H=0`, the affine geometry profile is constant:

```text
G_a,0(X,h) = h_ref.
```

Thus

```text
Gamma_a,0(X) = h_ref
```

is an exact invariant section. Because the output is constant at the neutral
profile, the section derivative of the graph transform vanishes there:

```text
D_Gamma T_a = 0 at kappa_H=0.
```

The same zero-duration identity limits used in RG-2a make the lagged base maps
locally invertible near `Delta_t=0`. Local invertibility alone does not provide
one fixed graph-transform domain. Choose nested charts `K_minus` compactly
contained in `K`, with `K` compactly contained in the admitted smooth chart
`U`. Freeze one family-local extension profile completion in finite-dimensional
local coordinates so the lagged state and geometry maps:

```text
agree exactly with the candidate maps on K
return outside a compact neighborhood to X+ = X and h+ = h_ref
preserve the required uniform derivative bounds.
```

The extension is fixed profile configuration. It is not causal state, history,
runtime tuning, or evidence that the original local equations select one
extension independently. Its construction must be graph-relabeling and
reorientation equivariant.

For every section in the admitted class, write the extended base map as

```text
Psi_a,Gamma(X) = X + f_a,Gamma(X).
```

Choose positive `Delta_t` small enough that

```text
Lip(f_a,Gamma) < 1.
```

The extended base map is then globally invertible on the fixed coordinate
domain, with

```text
M_inverse <= 1 / (1 - Lip(f_a,Gamma)).
```

Require, for every admitted section,

```text
Psi_a,Gamma(K_minus) is a subset of K.
```

The fixed section obtained on the extended domain is restricted to `K_minus`.
For every `X` there, both `X` and `Psi_a,Gamma(X)` remain in `K`, so the
invariance equation uses only real candidate maps and section values inside
the real chart.

Use the complete metric space of uniformly bounded Lipschitz sections with
value radius `r`, Lipschitz ceiling `L_Gamma`, and sup-norm metric. Define the
typed geometry gain

```text
epsilon_H = norm(D_K H_profile)_(K4 -> geometry).
```

For the accepted affine profile, `epsilon_H` is proportional to
`abs(kappa_H)`, but the theorem does not identify their units.

Let finite local constants satisfy

```text
M_G       bounds the normalized geometry source map
L_G_h     bounds its geometry derivative
L_G_X     bounds its state derivative
L_Phi_h   bounds the lagged commit map's geometry derivative.
```

Choose the section radius and coupling so that

```text
epsilon_H M_G <= r
```

and the Lipschitz self-map condition

```text
epsilon_H (L_G_X + L_G_h L_Gamma) M_inverse <= L_Gamma.
```

Section variation contributes to the contraction estimate. The safe bound is

```text
q_a,0 <= epsilon_H [
           L_G_h
           + (L_G_X + L_G_h L_Gamma) M_inverse L_Phi_h
         ]
      < 1.
```

Banach's fixed-point theorem on that fixed complete Lipschitz section class
supplies one unique local Lipschitz invariant section `Gamma_a` near `h_ref`
for the frozen extension completion and sufficiently small positive `Delta_t`
and `epsilon_H`. Extension-independent uniqueness is not claimed.

The neutral section alone is not the proof. Fixed-domain extension, uniform
inverse, value and Lipschitz self-map, and corrected contraction conditions are
all load-bearing. `C1` regularity requires a separate derivative-graph or
`C1,1` bunching theorem and remains analysis debt rather than family-admission
evidence.

## Why This Is A Distinct Family

The invariant-section architecture is not CI because `J_k` and `h_k+` do not
participate in one simultaneous root. It is not OS because `h_k+` does not feed
a later current substage during beat `k`.

Instead:

```text
h_k = Gamma_a(X_k)
J_k uses h_k
h_k+ is generated after J_k
X_k+1 commits
invariance guarantees h_k+ = Gamma_a(X_k+1)
h_k+1 is reconstructed exactly without persistence.
```

`Gamma_a` is not an independently authored runtime law. Relative to the frozen
extension completion, it is the unique family-local constitutive section
derived from the invariance equation, so it has no extra runtime tuning
freedom. Fitting, learning, or updating it from trajectory history, prior
roots, prior geometry, caches, or solver continuation state would make it a
hidden persistent carrier and invalidate this classification.

Because the lagged transition, generated-geometry map, nested charts, and
frozen extension completion are equivariant, transforming a fixed section
gives another fixed section. Uniqueness relative to that completion therefore
forces

```text
Gamma_a(rho_X(g)X) = rho_h(g) Gamma_a(X).
```

The covariance result is limited to that unique local chart.

## Persistent-Carrier Handoff

The local RG result removes information deficit as the default PC premise.
Persistent-carrier pressure should instead ask whether additional structural
authority enables capabilities outside the local invariant-section domain:

- continuation where the commit map loses local invertibility;
- multivalued section or branch choice;
- topology, selector-rank, active-set, or boundary events;
- context changes not represented in current state;
- constitutive hysteresis or history unavailable from `X`;
- a larger coupling or step-size domain.

PC may still seek a minimal sufficient carrier if one of those capabilities
requires it. It must not default to persisting full `h` or claim that local A/C
committed state is insufficient.

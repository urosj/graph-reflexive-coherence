## What is closed

Each named program has reviewed scientific results, a bounded constructive
source/target mechanism, reference/conformance evidence at its stated scope,
and explicit ledger/source admission. The five-realization summary is
derived from those admitted ledgers, not a second claim registry.
The `atc-rgatc-query summary` command validates the complete predecessor
chain and returns source-bound rows for all five.

A_OS's generalized program is not imposed as an identical domain on the
paired CI/PC/CIP results. RG2b's concrete completion uses a much smaller
frozen beat/gain and has a Lipschitz-only section. Acceptance does not imply
equal performance, common parameter domains or uniform finite-work success.
The accepted results are not merely OS formulas renamed for five products.

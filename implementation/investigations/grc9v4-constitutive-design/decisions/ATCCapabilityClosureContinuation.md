## 1. Correction to the forward objective

The [independent review](../evidence/autonomous-topology-change/review/ATC2-IndependentReview/ATC2-IndependentReview.md)
supports the bounded ATC-2 results. The
[subsequent correction](../evidence/autonomous-topology-change/review/ATC2-IndependentReview/ReviewCorrection.md)

endorsed capability-gap-driven **V4-native** scientific design, with the older
substrates as directional hints rather than formulas to transplant.

Introduce **ATC-CAP-REQ-01**, an open aggregate research/implementation
requirement, not an admitted scientific claim. Its working minimum is:

1. Relation growth between existing vertices.
2. Endogenous refinement that increases the number of resource coordinates.
3. Simplification/coarsening.
4. A complete constitutive composition of these capabilities within a run.
5. Continued native autonomous operation after graph change and restoration.

Each of the first three capabilities needs a justified, nonempty operative
domain in **each** of A/C × OS/CI/PC/CI+PC/RG2b. That is thirty required
capability/family cells, not a promise that every state triggers, every target
admits, or all families follow identical trajectories. A read-only method, an
identically inactive witness, a supplied partition or a successful call made by
an external script does not close a cell. Valid no-event states, unresolved
symmetry, resource limits and target rejection remain necessary behavior.

The three positive ATC-2 event fixtures remain useful partial evidence. They
do not replace onset, composition or continued autonomy. Birth there adds an
edge, not a vertex; merge removes a vertex. Their combination alone cannot
provide vertex growth. Keeping the structural split law held is scientifically
correct, but the **refinement capability stays a blocker**, not an optional
feature that can disappear at synthesis.

Exact quotient preservation, universal attractor preservation, a completed
core spark, restoration/formation interpretations, independent vertex seeding,
Lorentzian completion and hierarchy are not made mandatory by this requirement.
Their original claim-local activation conditions remain. A proven obstruction
to a required capability requires an explicit architectural decision, not a
quietly weakened support table.

## 4. First exploratory question: incident response information

**Working hypothesis, not a selected law:** finite resource redistributions may
expose distinctions between incident response channels that a single current
geometry score does not capture. Such information could help formulate a
V4-native refinement or relation criterion. It does not by itself establish
that the current representation is inadequate, nor that changing it is useful.

Consider a declared finite set of charge-preserving changes to current C,
holding W/Z, profile, reference and context fixed. Recompute the unchanged
profile-correct present-state read at each admitted input, without an ordinary
step, writer or event. Retain the finite current differences, not an inferred
Jacobian or reduced Hessian. For the current unit-measure domain, pairwise
redistributions are possible probes; a general metric/frame and neighborhood
choice must still be justified. A failed probe admission means unavailable
evidence, never an instability certificate or a reason to enlarge the chart.

This differs from selecting whichever future edited graph has the best outcome:
there is no topology search, target evaluation, future-trajectory optimization
or operation chosen in the probe. The probe is also not a free observer-to-writer
shortcut: any eventual constitutive consumer needs explicit accepted authority.

## 1. What is built

This is an executable **full-graph** reference for the reviewed nonlinear A_OS
law, not another paired-coordinate trajectory using the earlier reduced
certifier. It assembles incidence, differential descriptors, site potential,
reference Read-Back, generated geometry, fresh Read-Back, continuity and the
post-resource history writer. It also executes the single prescribed local
fission operation and a small research transaction owner for both actual roles.

The profile preimage binds all physical and computational operands: the two
source/target graph classes, host coordinates, unit reference weights, ridge,
nonlinear potential, conductance/geometry parameters, writer time constant,
and numerical recipes. Its content identity has a research-only schema; it
is not a native potential ID or an admitted production profile. Parameters
and graph tables are read-only; retained interval endpoints are detached and
immutable under ordinary assignment.

The concrete common fixed law used for conformance is

$$
p(c)=\frac{19}{4}c+\frac{1}{2\cdot65536}c^2,
$$

with alpha=beta=3/8192, gamma=3/4096, chi_A=3/64 and
kappa_H=kappa_Ah=3/4. All lie in the accepted G5–G6 domain. Selecting this
law makes execution possible; it does **not** narrow or replace the already
accepted C¹ theorem. The executor does not claim to represent every C¹ function.

The physical tau is still 1/(8 log 2). The separate represented experiment
pins binary64 tau as `0x1.71547652b82fep-3`, not as the exact transcendental
constant. These two meanings never share an unqualified parameter label.

## 2. Stages and independent comparison

For each graph the full evaluator computes:

1. Reference descriptors D(C), full p(C), potential and baseline; reference
   selected current and its structural form.
2. The actual star tensor and generated H, followed by a fresh current and
   H-inverse structural form. The actual star-difference residual is checked
   against 1/512, not merely assumed from a profile label.
3. Continuity using that fresh current. A negative or uncertified resource
   proposal stops before the writer; it is not clamped or advanced.
4. D(C+) rebuilt from admitted post-resource C+, conductance driven by the
   fresh current, and log interpolation with the correct rho(h).

The evaluator uses the unchanged outward 256-bit rational interval kernel.
It is compared with a separately assembled 110-digit Decimal oracle that
uses edge-local accumulation, independently evaluates WLS and assembles the
star, and solves its own dense system. It does not call the full evaluator's
read or step functions. Decimal agreement is a cross-check; **the outward
intervals supply the enclosure**, not an assumption that Decimal is exact.

Eight point comparisons cover both source/target pairs at h=1/8 and h=3/25.
They check 1,116 scalar quantities, including intermediate potentials,
baselines, descriptors, selected currents, structural forms, geometry,
writer operands and next C/W. Every oracle value lies inside its corresponding
enclosure. The reference also distinguishes these wrong stage substitutions:

- Writer descriptors taken from source C rather than C+.
- Writer current taken from the reference read rather than the fresh read.

This is stage conformance for these explicit inputs, not a parameter campaign
or universal finite-precision proof for the whole mathematical box.

## 3. Source selection, target construction and actual roles

Exact rational source preimages are retained separately from their outward
enclosures. The source admission checks those preimages, exact charge and
pairing; mere overlap of interval charge with the required total would be
insufficient. The two inputs belong to the accepted paired/embedded domains.
Reset is independently constructed and distinct from current in resources
and histories. It is not an allocator input.

The operation consumes source **reference** current. It accepts a dyadic share
only when the entire computed interval rounds to one round-even integer k.
An interval crossing rounding cells returns unresolved; it does not choose a
convenient target. Exact half-bin tests cover both tie parities. The paired
input selects k=32775 and the embedded input k=31897. Their represented source
reads select the same certified bins at these inputs.

That represented-bin comparison does not admit the rounded embedded source
into the exact-charge theorem: its total need not equal 41/5 exactly. This
distinction is retained in the record.

The construction is fixed: split the declared parent into its two sectors,
transport each role's resources by the same current-selected dyadic share,
preserve every old edge's own history, and seed only the new bridge at one.
For the embedded graph the old external edges move to target indices five
and six, while the bridge occupies index four. The explicit lineage map
checks this reindexing; array-length agreement alone would not suffice.
Both children inherit the parent host position. There is no target search,
old-edge reinitialization, temporal trigger or new symmetry tolerance.

Both roles undergo full detached target evaluation/readmission before
publication. The paired target's first admissible step must enter its return
ball; the embedded target is already in its return ball. This numerical check
is not a hidden committed ordinary step during the event. It verifies the
reviewed entry implication without replacing the transported event state.

## 4. Research lifecycle, failure and replay

The local owner publishes the new graph, current, reset, parent reference and
event metadata in one assignment, after both-role checks. Ordinary steps
preserve reset; reset after fission and an ordinary step restores the actual
transported reset, not the source reset or current state.

The retained pressure includes:

- Missing source lineage, wrong profile, invalid old-edge map and forged reset
  history, even when the attacker recomputes the outer digest.
- An inadmissible reset-only transfer domain with current unchanged.
- An **injected** reset-only readmission failure after current readmission
  passes, and a separately injected late publication failure. These are
  lifecycle fault injections, not claimed physical counterexamples to the
  G5–G6 both-role theorem.
- Out-of-domain requests, unresolved allocation, exact ties, and attempted
  mutation of a retained scientific endpoint.
- Immediate event replay, plus full split → ordinary step → reset replay from
  the pinned source, checking every predecessor/successor identity. Changing
  the replayed request is rejected even if other fields are left plausible.

Every tested failure leaves the complete old publication pointer unchanged.
Replay re-executes physical selection, transfer and readmission; it does not
accept a digest as proof of the claimed science. History/provenance metadata
are not read by the physical current law.

The ordinary unsplit controls use the new full-graph evaluator and alternating
h=1/8,3/25. For these inputs the paired no-split/reset-to-one-only controls
reject through resources at attempts nine/eight; both embedded controls reject
at attempt six. Failed proposals execute no writer, publish nothing and invoke
no event fallback. Those finite observations are consistent with, and narrower
than, G5–G6's uniform horizon theorems. They do not replace those theorems.

This owner supports the bounded event and sequence stated here. It is **not**
the native K0 scheduler, a generic graph-event dispatcher, a receipt-wire API,
a complete lifecycle security audit or an implementation of indefinite
repeated autonomous fission. Source formation into the event domain is not
proved by supplying an admissible source preimage.

In particular, this wrapper admits splitting from its retained exact-rational
event-state preimages. An ordinary source step does not manufacture a new
exact preimage: subsequent source-to-event admission is not implemented here.
The source controls exercise ordinary failure, while event conformance begins
at the separately admitted event boundary. This is an explicit G7-R scope
limit, not evidence of automatic formation or autonomous event dispatch.

## 5. Represented-error bridge: what is and is not closed

For each graph and each independently transported role, run sixteen steps of
the fixed repeating schedule

$$
(1/8,\ 3/25,\ 31/250,\ 121/1000).
$$

The reference trajectory propagates exact-real enclosures. The separate
represented experiment starts from binary64 projections and, at every step,
uses the represented h and fixed represented tau, encloses the full stage,
then rounds each published C and W to a uniquely certified binary64 value.
When representing the lower request endpoint, use the next float **above**
3/25: the usual binary64 spelling `0.12` is just outside the closed domain.
No parameter is selected after observing a target outcome.

This is a precise **publication-only rounding recipe**. Intermediate currents,
geometry and descriptors are enclosed without intermediate binary64 rounding.
It is not asserted to be the production staged arithmetic, which has additional
rounding boundaries. The future native implementation must either adopt an
authorized recipe or have its own staged-error comparison.

The recorded infinity-norm error at each step encloses the difference between
the entire exact reference enclosure and the entire represented result. Thus
earlier projection errors, represented h and represented tau are carried
through the next nonlinear step; this is not merely a one-step comparison
reset to the ideal state each time. The predeclared finite acceptance bound is
1e-10 for each C and W error. Actual maxima are below 4.1e-16 for C and
8.3e-17 for W over all four sixteen-step runs. Every exact and represented
target checked stays in the stated return ball with positive resources.

Each row retains both rounded state images, exact enclosure identities,
stage identities, exact rational error upper bounds, requests and residuals.
The checker reconstructs the full enclosures and intermediates; the record
does not require an ignored output folder or machine-local input path.

### A real numerical boundary: exact conservation is not binary64 conservation

The exact continuity/surgery law conserves charge algebraically. Independent
binary64 publication of resources does not preserve that identity exactly.
The observed charge discrepancy reaches 11/5629499534213120 (about 2e-15)
in the embedded current run. It is recorded, **not normalized away**.

Consequently this package closes a bounded finite represented-error comparison,
not exact native conservation or an infinite binary64 trajectory theorem.
Before native admission, choose and justify a conservative representation or
a declared error/conservation policy, then prove the needed forward-invariant
numerical domain. It would be incorrect to apply the exact-charge theorem
unchanged to arbitrary rounded publications, or to add a balancing correction
without scientific/numerical authority. Similarly, finite agreement of k
does not establish arbitrary-state native quantization covariance.

The G6 paired q margin is only about 0.000621 below 9/10. Neither this finite
experiment nor future native work may treat that margin as free permission
to widen steps, potentials, geometry or feedback parameters.

## Gate Question

D6-v2 leaves all three candidate-local current closures regular and eligible
for transition work. D7-v2 asks a stricter question:

> Can each candidate now supply one complete, stage-ordered, Markov-closed,
> atomic, and accounted candidate-local transition without inventing a
> load-bearing constitutive arrow?

This gate does not derive the common global structural map. In particular,

```text
candidate-local K_4^a -> H_4 -> h_4 -> later candidate consequence
```

remains D7G work. D7-v2 therefore cannot select an architecture or send a
candidate directly to D8.

## Ontological Differentiation

D7-v2 has produced a useful comparison without ranking the candidates:

```text
A:
  independent retained mobility
  + explicit cross-beat writer

B:
  independent structural carrier
  + complete conditional constitutive/read-current mechanism
  - endogenous formative writer

  no independent carrier state

  + complete formal projected-sector recurrence
```

The distinction is not merely which equations happened to be completed first.
A and B both posit an independent retained coordinate, so each needs a law that
writes that coordinate across beats. A has one; B does not. C instead asserts
`T_C=P_M,Delta C`, so an independent `U_C` would duplicate causal authority.
Continuity writes `C`, after which the selected content is recomputed.

This yields the central D7-v2 interpretation:

```text

C separates formal projected-sector recurrence from dynamical retention.
```

For D7G, A and C therefore pose different integration questions. D7G must test
whether their distinct local recurrences remain causally coherent when coupled
to the common `K_4 -> H_4 -> h_4` crossing. B has first identified the missing
plasticity/remodelling theory needed before that crossing can be asked of it.

## Candidate B: A Real Boundary, Not A Trivial Rejection

```text

```

D4-v2 through D6-v2 also close its type, covariance, bounded generalized

But B is an independent cross-beat state. It therefore still needs:

```text

  -> declared downstream consequence
  -> exact U_B
  -> T_B,k+1.
```

D2 froze that arrow as:

```text

```

No frozen source subsequently derives it. D7-v2 pressure-tested the obvious
ways to fill the gap:

| Proposed family | Disposition | Reason |
|---|---|---|
| copy A's log-geometric writer | rejected | A updates positive scalar mobility toward an existing `G_W` target; B is a signed bilinear carrier with no such target |
| EMA of a current or geometry observable | rejected | slow cache behavior does not establish B's formation, release, capacity, or independent authority |
| `J_C tensor J_C` target | rejected | the tensor is sign-even and positive semidefinite; it does not derive the admitted signed `T_B` family |
| difference of current tensors | not admitted | reference, gain, normalization, sign, and release semantics would be new post-hoc theory |
| relax `T_B` to zero | insufficient | supplies a possible release but no formation or counter-write |
| hold `T_B` fixed | control only | tests B's read authority but is not a transition |

Inventing one of these merely to keep B alive would violate D7-v2's central
rule: no load-bearing constitutive arrow may remain requirement prose or be
filled by convenience.

B therefore receives:

```text
current_tranche_closed_missing_constitutive_derivation
```

This means:

```text
B ontology remains coherent.
B geometry, Read-Back, and current closures remain valid bounded work.
B is not a D7G survivor in this tranche.
A and C are not preferred on theoretical grounds.
```

More precisely:

> B is a complete conditional constitutive/read-current mechanism, not a
> complete formative mechanism.

Given an admissible `T_B`, the accepted B equations specify what that structure
does to geometry, Read-Back, and current. They do not specify how `T_B` forms,
reconfigures, or releases endogenously. The missing theory is therefore closer
to plasticity or remodelling:

```text

  -> formation or reconfiguration of signed capacity
  -> T_B,k+1
```

A future named theory or constitutive successor may reopen B by deriving an
exact `U_B` with carrier type, units, capacity, formation, retention, release,
covariance, and lifecycle semantics. The archived B debt is retained explicitly
for that purpose.

on-manifold selected-sector perturbation changes the response while a matched
complement perturbation does not. D6-v2 closed the authoritative current. D7-v2

That is not yet proof of dynamical retention. D7-v2 distinguishes:

```text

  closed at the formal recurrence level

  open pending D8
```

D8 must supply the executed branch, clock, horizon, norm, persistence
criterion, and stability classification after forming preparation is stopped
or standardized. A low spatial mode is not, by itself, a slow temporal mode.
C survives D7-v2 because no constitutive writer is missing, not because temporal
persistence has already been shown.

# Public native spark workflow

Start with the [public guide](../../../../../../examples/grc9v4/native_spark.md)
and [executable example](../../../../../../examples/grc9v4/native_spark.py).
The guide assembles the accepted family results into source → expansion → proof
admission → certified entry → positive window → completed spark, including
configuration, both histories, local gain, reset and replay.

Use **Open native spark workflow** in the Phase 9 browser, notebook cell
`native-spark-workflow`, or:

```python
from grcv4_explorer.spark_native_workflow import native_spark_workflow
workflow = native_spark_workflow(repo_root)
```

`/api/native-spark/workflow` returns the checked all-ten overview and portable
commands. `/api/native-spark/workflow/source?name=guide`, `name=code` and
`name=publication` expose the exact tutorial sources. These are fixed read-only
routes. Inspection never starts a numerical job; failure clears old output.

The CLI's `prepare` and `run` commands explicitly execute the public model.
Cold checkpoint `replay` executes the saved journal. The web/notebook supplies
these commands without launching them. Existing family panels retain the
accepted detailed numerical/cold-replay evidence, with historical flags intact.
The new tutorial does not grant broader completion, hierarchy or G4.

The bounded publication was accepted on 2026-11-03. The current view embeds
the separate acceptance decision, also available at
`/api/native-spark/workflow/source?name=acceptance`. The original publication
keeps its validation-time acceptance flag and source identities.

# C_PC spark-completion research

The Phase 9 browser has a **Spark completion — current research** panel.
It shows the bounded C_PC source-to-completion result, including the full
resource/carrier trap, each history's entry/window/gain, indexed evidence
and review limits. The result is pending scientific review and adjudication.
The adjacent accepted-applicability panel preserves C_OS/C_CI authority.

Read-only API: `/api/spark-completion/applicability/research`.
Source bytes: `/api/spark-completion/applicability/research/source?path=...`,
restricted to the returned source index. Browser and API reject changed
bindings and clear stale output on a failed refresh. No numerical campaign
runs during inspection.

The verification notebook includes cell `spark-completion-research`.
Python callers can use `grcv4_explorer.spark_research.spark_research_status`
with the repository and side-tool roots. This research projection does not
add accepted forensic-graph claims or native completion capabilities.

The [investigation](../../../decisions/SparkCompletionCPCApplicability.md)
contains the mathematics, exact scope, commands and next review step.

## Main results

For the declared source and target graphs, the explicit completion has base-increment Lipschitz bound 17/64, inverse bound 64/47, section Lipschitz image bound 17/47 below the chosen ceiling 1/2, graph-transform contraction 2/47, and global geometry displacement at most 1/16384.

The fixed positive profile uses beat 2^-25 and geometry gain 2^-32. A whole-section-envelope calculation proves a successful inactive-to-active ordinary source transition and the uniquely rounded source-only index 32768. The target is positive and invariant for both roles; no-split and W-reset-only controls cannot remain positive indefinitely. The old large-beat first-entry claim is deliberately not reused.

## Important limits

The completion is NEW and proposed. It uses auxiliary resource coordinates through zero and a globally Lipschitz floor-preserving extension. Negative PHYSICAL resources are not admitted. It is not an already-shipped native completion, and the numerical profile is a conservative existence point rather than a practical native operating recommendation.

No invariant-section solver is implemented or executed here. No native RG2b beat is run. The interval computations verify implications for every unknown section value in the proved envelope; they are not a trajectory generated by substituting a supplied geometry or a CI root. No source/debt ledger is modified. Independent scientific review, source admission, executable section/reference work and native integration remain separate.

## Reproduce

Python 3.10+ and the standard library are sufficient.

```sh
PYTHONDONTWRITEBYTECODE=1 python check_rgatc_ta.py
PYTHONDONTWRITEBYTECODE=1 python pressure_rgatc_ta.py
```

The pressure checker compares its fresh result to the included certificate. Run it from any working directory; it resolves inputs relative to its own file.

The single retained dependency in `deps/retained/arithmetic/` is copied unchanged from the mounted `certify_atc_sector_readback_point.py`. Only its outward arithmetic and matrix primitives are used. Its old standalone trajectory/main routines are never invoked. The new verifier's log enclosure uses the retained atanh-series construction from the G5/G6 arithmetic. No third-party packages or internet access are required.

These are internal checks, not an independent auditor's acceptance. SHA-256 bindings are in the certificate and package manifest.

## Reproduce

Python 3.10 or later; standard library only. From this directory:

```sh
PYTHONDONTWRITEBYTECODE=1 python check_rgatc_er.py --check
PYTHONDONTWRITEBYTECODE=1 python pressure_rgatc_er.py
PYTHONDONTWRITEBYTECODE=1 python check_rgatc_er.py --compare
```

`--check` verifies the retained record digest and bound code bytes only. The pressure script checks retained exact inequalities and consistency; it does not rerun the numerical suite. `--compare` actually reruns the full E/R suite and requires exact equality of the complete regenerated certificate. Without flags, the checker prints newly executed evidence. `--write` explicitly replaces the retained certificate with a fresh run.

The included `REPRODUCTION.json` records the completed repeat execution and identity check. Run timings, process identifiers, and caches are not certificate authority and are not included in its digest. Pure elementary-function caches contain no geometry/section or physical-state history.

## Frozen physical and numerical contracts

The physical profile retains Delta=2^-25, kappa_H=2^-32, and exact tau=1/(8 log 2), with the active Candidate-A parameters and auxiliary floor-preserving completion from T/A. Only C/W is authoritative. The section is evaluated from scratch at each state and is not transported across topology.

Ordinary reads use a default 24-level finite graph transform with an error budget of 10^-34 and at most 16 inverse corrections. Each section result also binds its actual numerical policy. This finite budget is fail-closed, not a universal termination guarantee on every point of the global theoretical completion.

The finite represented experiment projects C/W to binary64 at publication and uses rounded tau in the numerical W writer. It still evaluates the section of the original exact-tau physical completion. A separate local defect bound accounts for that mismatch. It is not an all-binary64 internal implementation or an indefinite numerical theorem.

## Important limits

The positive source impossibility horizon and indefinite target limit remain T/A theorem conclusions; hundreds of millions of source steps were not executed. The retained E campaign executes one source onset, three target steps per role, and two steps per unsplit/history-reset control. The additional R runs execute separate lifecycle, covariance, failure, and four-step represented checks.

The profile is a conservative existence example. This package does not demonstrate practical large-step native performance or source-admit the new auxiliary completion. Independent review and production work remain separate.

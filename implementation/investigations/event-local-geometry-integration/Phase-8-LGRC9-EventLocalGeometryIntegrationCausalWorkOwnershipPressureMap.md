## Purpose

The C1 scope result showed that the place where an event occurred was not the
native source of the current that followed. This investigation asks what could
legitimately own the next causal work. It is a source-backed pressure map, not a
mechanism design, experiment registration, or implementation gate.

It consumes the C1 registration, raw evidence, and post-C1 interpretation; the
native GRC9V3 current reconstruction and LGRC9V3 packet contracts; bounded
support, boundary, and circulation context from N21, N24, and N28; and the
Read-Back distinction between retained formation, present current, and
write-back.

## Native Authority Is Already Distributed

The current runtime does not assign all causal authority to one object.

| Function | Native carrier or authority | What is established |
| --- | --- | --- |
| Current orientation | GRC9V3 oriented edge flux | Direction is reconstructed from node potentials and positive conductance; no action owner is assigned. |
| Packet debit | Source node | Source coherence is debited when departure is processed. |
| Packet credit | Target node | Target coherence is credited when arrival is processed. |
| Scheduling | Declared producer or caller | A departure event is queued; scheduling alone does not debit coherence. |
| Mutation | `LGRC9V3.step()` event processing | Departure and arrival transitions commit debit, in-flight state, and credit. |
| Route/pole aggregation | Producer-configured policy surface | A route or surplus relation may select a source, but that does not naturalize remote event-conditioned ownership. |

This decomposition is the main source-level result. The question "who owns the
work?" cannot be answered by pointing to current direction alone. Native
current, budget responsibility, scheduling authority, mutation authority, and
receipt are distinct.

## Ownership Candidate Pressure

### Event locus or trigger node

Node 0 received the registered event but was a native current sink. Trigger-
owned emission is therefore rejected in the registered C1 fixture. Reversing
the current or broadening action scope after observing the result remains a
failed-closed path.

### Native current source node

This is the strongest mechanically grounded candidate for **debit
responsibility**. Nodes 1 and 2 sourced the reconstructed current, and LGRC9V3
can debit an explicitly named source node through packet departure.

It is not yet a causal-work ownership result. No native contract makes the
remote event-conditioned relation locally available to those source nodes. If
a global orchestrator reconstructs the graph and selects them, the
orchestrator remains the mechanism.

### Edge or distributed current relation

GRC9V3 current is naturally relational: it is an oriented edge flux, not a
node-owned substance. LGRC9V3 packets also retain edge identity. However, an
edge currently owns no coherence budget, scheduling policy, or mutation
surface. Field- or edge-owned work would therefore require a new runtime
ontology rather than a reinterpretation of existing current telemetry.

### Route, pole, basin, or composite

Existing native producers can evaluate configured routes and pole surplus and
then schedule work from a source node. This demonstrates a composite policy
surface, not primitive route or basin ownership. The route meaning is declared
by configuration, and the actual debit remains node-local.

### Event queue or `step()`

The queue and `step()` own committed transition order and mutation. They do not
decide why work is eligible. Mutation authority must not be relabelled as
causal-work ownership.

### External global orchestrator

The orchestrator can reconstruct current globally and choose a convenient
source, but it is the identified hidden mechanism. Removing it must not remove
the effect in any native ownership claim.

## Read-Back Pressure

The Read-Back source keeps three objects distinct:

```text
retained formation
present current conditioned by that formation
write-back from present activity into later retention
```

Stored formation alone is not active current, and present current alone is not
read-back. A reflexive closure requires both a read path and a write path. It
also keeps the coherence-only state boundary: no independent memory or
read-back field is admitted as a primitive, and the exact nonlinear closure
remains open.

C1 does not satisfy this relation. It records an event-conditioned global
reconstruction and an action-scope failure, but no retained formation that
conditions present current and no source-backed write-back into later
retention. The ownership investigation therefore cannot promote C1 to
Read-Back evidence.

## Prior Experiment Pressure

The earlier experiments constrain downstream meaning without deciding
ownership:

- **N21** supplies bounded withdrawal and naturalization context while leaving
  native support and general naturalization blocked.
- **N24** supplies bounded surplus-supported optionality and a separate
  producer-mediated flux scaffold while leaving native flux-envelope debt.
- **N28** supplies bounded generative, extractive, and competitive/neutral
  exchange patterns under shared classification rules. It does not establish
  semantic cooperation, resource ownership, or causal-work ownership.

These results make reception, emission, and redistribution useful future
distinctions. They do not allow incoming current to be named support or a
source node to be named an agent.

## Function And Reusability Boundary

Future work must distinguish:

```text
reception      = incoming current or later target credit
emission       = source debit and outward packet work
redistribution = conserved debit, in-flight transport, and credit
```

None of these names an ecological function yet. A reusable candidate should
support at least two independent constructions without redefining ownership by
fixture. Prospective uses include support recruitment or boundary uptake,
route continuation, and environmental capacity circulation, but this pressure
map supplies evidence for none of them.

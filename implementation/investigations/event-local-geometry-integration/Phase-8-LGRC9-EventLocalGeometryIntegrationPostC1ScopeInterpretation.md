## Open Ownership Models

Three organizations must remain separate.

1. **Trigger-owned action.** The event locus owns outward current and emits
   work. This was the registered C1 form and is unsupported in this fixture.
2. **Source-owned distributed action.** The event changes a relation, another
   node becomes a native current source, and that source owns its departure.
   This is plausible but unregistered and unexecuted. It requires a local,
   causally available update rather than global source selection.
3. **Field- or edge-owned transport.** A relation carries transport before node
   ownership enters at debit, arrival, or update. This is a different runtime
   ontology and is not supported by the current evidence.

The present result selects none of the latter two.
